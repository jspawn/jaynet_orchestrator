# JayNet v1.41.0 — natural recall, evidence and routing reliability

Feature release focused on retrieving the right local context, compacting
without losing evidence, and making multi-model runs measurable.

## Scoped natural recall

Explicit recall questions can now retrieve local evidence before the brain's
first turn instead of relying on the model to remember a tool name:

- memory prefetch triggers only on explicit recall intent, not storage requests;
- RAG requires a configured collection or one named in the request;
- results are owner-scoped, depth-0 only and capped by
  `tool_selection.recall.max_chars`;
- calls appear in the trace and private hits taint the run normally.

Automatic RAG remains off while `tool_selection.recall.collection` is null.
The KG gains canonical aliases, optional confirmation-gated entity merges and
weighted associations. RAG score filtering now happens before reranking, so a
reranker cannot resurrect weak evidence.

## Evidence-aware transcript compaction

Old tool output now compacts according to what it contains:

- superseded reads of an identical file slice become re-read pointers;
- execution logs keep their command, exit code, head and error tail;
- recent and pinned results stay verbatim, and only the newest image remains
  inline;
- full output remains recoverable with `trace.query`.

Compaction events report exact saved characters and estimated saved tokens,
including elided images.

## Model routing and server lifecycle

- Vision is resolved per run from the target preset's `caps.vision`. Delegates,
  spawned agents and chains no longer inherit the brain's image capability;
  text-only children receive an explicit marker instead of an image payload.
- Swap-back now plans eviction for the temporary swap-in before restoring the
  original model, preventing occupied-GPU restore crashes.
- Specialist fallback remains available for service resilience, but recent
  requested/served mismatches are visible in Admin → Status → Overview. Eval
  fallback evidence is scoped to the case's run tree and invalidates affected
  rows by default rather than measuring the wrong model.
- Process cards show generation/prefill throughput for vLLM and radiance, with
  non-finite Prometheus values rejected.
- The Hugging Face downloader lists `.rad` containers and `.recipe` files and
  can draft a radiance-shaped preset.
- New `specialist-qwen38-efficientthink-apex` preset and strict tool-calling
  chat template for the EfficientThink APEX DFlash2 specialist.

## Eval harness hardening

The delta failure pass fixed several ways a harness could manufacture a red or
green result: BFCL imports now use the last user message, tool expectations
match per-turn call multisets, and gate-blocked calls count as never executed.
Suite preflight probes fallback-source aliases; fallback-invalidated cases get
exactly one retry after the source recovers. Judges receive exact `ask.user`
questions and scripted answers, so clarification behavior can be graded from
what actually happened.

## Imagegen backends and tool guidance

`plugins.imagegen.backend` selects a registered image backend. New engines
implement the small transport contract in `plugins/imagegen/server.py` and
reuse the existing slot hibernation, readiness, output and shutdown lifecycle;
`image.generate` stays unchanged.

The orchestrator prompt now discovers cloud aliases and roles from the live
`llm.call` schema rather than a hardcoded model list. Browser descriptions
point to the supported `web.fetch(js=true)` path, and `code.run` documents that
backgrounded processes do not survive the call.

## Dependencies

LiteLLM 1.102.2 and dnspython 2.9.0 address current dependency advisories;
lockfile refreshes also include filelock 4.2.1 and opentelemetry-api 1.45.1.

## Upgrading

Pull and restart. Database migrations are additive and automatic. Re-sync the
LiteLLM environment from the updated lockfile (`scripts/setup.sh` on a managed
install). No configuration change is required; natural memory recall is on by
default, while automatic RAG recall stays disabled until a collection is set.
