# v1.20.2 — 2026-10-06

Harness fixes from the v1.20.0 delta post-mortem: all 19 failed cases
were trace-audited, and five issues turned out to be ours, not the
models'.

## Vacuous specialist checks fail review now

Two delegates returned `verified: true` with checks that can't fail:
`assert … or True` (tb-huarong-dao — the solution was invalid) and a
literal `python3 -c "print('ok')"` (gaia-65afbc8a).
`review_delegation` now lints the specialist-authored check
deterministically before any model call: tautologies and checks that
reference none of the task-named deliverables fail closed with zero
LLM spend; a missing task-named output in `files_changed` is flagged
in the review evidence (deliberately not a hard fail — shell-written
files don't always register).

## Stall ladder stops punishing good diagnosis

The worst fail of the delta: six *distinct* diagnostic `code.check`
turns — fresh args, fresh results, root cause found — all counted as
no-progress; the hard stop armed; and the `fs.write` carrying the
diagnosed fix was **blocked**. The final answer stated the exact fix
it wasn't allowed to apply (tb-regex-log). Now:

- Non-repeat check turns (fresh args AND fresh result) are neutral on
  the ladder — identical-repeat check streaks still escalate.
- `fs.write`/`fs.edit` pass the armed hard stop; a real mutation
  disarms it. Byte-identical rewrites stay blocked, `code.check` stays
  blocked (verify-spin remains closed).

## Environment honesty in `code.run` / `code.check`

- The description claimed cwd = project root for python snippets; they
  actually chdir to ORCH_EXEC_WORK. Brains burned calls on
  `./solution.json` FileNotFoundErrors (feeding the stall ladder).
  Both tools now say: bash cwd = project root, python snippets chdir —
  use absolute paths.
- Bash-shaped input (`cd …`, `python3 <<EOF`) with `language=python`
  gets a loud re-issue hint instead of a `NameError: 'cd'`.

## Bot-wall pages get the headless-browser hint

An Anubis proof-of-work challenge (1068 chars) beat the 500-char
thin-content threshold and came back as "ok" content — no `js=true`
hint, though headless Chrome is exactly what passes those walls
(gaia-72e110e7). Bot-wall markers (Anubis, cf-challenge, "just a
moment…", proof-of-work, …) now mark a page thin regardless of length.

## Prompt aligned with the brain code gate

The gate prompt said "compute with `code.run`" while
`brain_mode: verify` removes `code.run` — three judge notes blamed a
routing choice the brain never had. The prompt now names `code.check`
as the brain's compute/verify lane (same engine, network off,
120s/200-line caps), and `code.check`'s description no longer points
at an unavailable tool.
