# v1.8.2 — vision + stt helper slots, mic dictation, llm.call images

2026-09-09 · Feature release. JayNet gains two CPU helper slots alongside
embed/rerank — a local vision model and a whisper speech-to-text server —
plus mic dictation in the chat composer and multimodal `llm.call`. No
breaking changes; both slots ship EMPTY and every new UI element stays
hidden until the matching preset is assigned.

## Presets: vision + stt helper slots

Two new optional boot slots (Admin → Presets → Boot model slots):

- **vision** — a llama-server with `--mmproj` (e.g. Qwen2.5-VL-3B on CPU),
  serving the new `local-vision` LiteLLM alias. The alias is rendered into
  the generated proxy config only while the slot is assigned.
- **stt** — a whisper.cpp `whisper-server` (e.g. large-v3-turbo on CPU).
  The new preset key `WHISPER=on` makes start-model.sh skip every llama
  flag and launch the whisper binary from the preset's binary-registry
  entry with its own argv.

Example presets ship as dummies: `presets/vision-qwen2.5-vl-3b.conf`
(:8098) and `presets/stt-whisper-large-v3-turbo.conf` (:8099).

## llm.call: image support

New optional `images` argument (data URLs or workspace image paths,
png/jpg/jpeg/webp/gif/bmp, ≤10MB) builds OpenAI multimodal content blocks.
With no explicit `model` the call routes to `tools.llm.vision_model`
(default `local-vision`); explicit cloud models with images keep the
existing cloud privacy gate. A down/unassigned vision slot returns an
actionable "assign a vision preset" error. The `image` skill now documents
vision-model image understanding with tesseract OCR as fallback.

## Tools: audio.transcribe

New private, read-only tool: posts a workspace-confined audio file to the
whisper server's multipart `/inference` endpoint (`tools.audio.stt_url`,
direct HTTP like rag.*) and returns the transcript. Comes with a new
`skills/audio` skill.

## Chat: mic dictation is back

A mic button in the composer records in the browser, resamples to 16 kHz
mono WAV client-side (whisper.cpp has no ffmpeg), and posts to the new
`POST /api/stt`, which forwards to the stt slot and drops the transcript
into the prompt. The button only appears when the whisper slot is actually
reachable (a `GET /api/stt` TCP probe) — no whisper, no button, no dead UI.
Recording state is a pulsing-red button so an open mic is impossible to
miss.

## Admin + downloader fixes

- **HF downloader: .bin files** — the repo file whitelist learned `.bin`
  (whisper.cpp models) as its own kind; `list_gguf` and preset suggestions
  stay llama-only, the admin list shows a "whisper" pill, and the model
  browser + preset file picker see `.bin`.
- **Binaries honesty** — the launcher's implicit default binary
  (`$LLAMA_BIN` → `$ORCH_HOME/bin/llama-server`) is now a visible read-only
  row in the Binaries panel with a missing-pill; start-model.sh's error
  points at the fix; `device_env` may be empty (CPU builds pin nothing).
- **Proxy re-render on preset edits** — preset/slot changes now re-render +
  reload the LiteLLM proxy config like cloud-model edits always did;
  assigning a vision preset no longer leaves its alias 404ing until a
  manual proxy restart.

## Fixes (audit #16, tag re-cut)

- `runtime.__version__` was left at 1.8.0 when 1.8.2 shipped — the release
  pin (`tests/test_release.py`) caught it; the tag was re-cut onto the bump.
- **MCP**: repinned `mcp`/`mcp-types` 2.0.0 → 2.0.1 (2.0.0 cannot import on
  py3.11 despite its `>=3.10` declaration) and the SDK import guard now
  converts any import-time breakage into the actionable McpError instead of
  leaking an HTTP 500.
