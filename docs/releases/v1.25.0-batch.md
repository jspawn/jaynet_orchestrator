# JayNet v1.25.0 — release note (rollup since v1.18.4, 2026-10-05 → 2026-10-12)

Eighteen tags in one week. The big arcs: the scheduler learned real
measured memory instead of hand estimates, the agent loop got procedures
and a 70%-smaller core, the knowledge stores became per-account, a
security hardening sweep closed two audit ledgers, and occamy 1.0 took
the brain crown. 2,355 tests green; all CI gates clean.

## Highlights

**Models & scheduling**
- **Measured scheduling.** `model.measure` hibernates the box, loads a
  preset, probes it once, and writes the REAL per-GPU VRAM + RAM into the
  preset. The loader packs by measured fit — a second model now loads
  alongside a half-full GPU tenant instead of evicting it (1.19.0).
- **imagegen can hibernate several slots — brain included** — for a big
  generation, and restores them with a readiness wait (1.18.6).
- **Separate-file MTP draft support** (`MTP_MODEL=` in presets) for
  checkpoints that ship the speculative head as its own file (1.23.0).
- **New reference brain: occamy 1.0 MiniPlus** — bakeoff crown
  (74/93 full delta, 20/30 on the flip set; table in
  docs/brain-bakeoff.md) (1.23.0).
- REDCELL OSINT specialist preset ships **archived** — upstream GGUFs
  are malformed (verified); kept for when the export is fixed (1.23.0).

**Agent loop**
- **Procedures**: `procedure.save/run/list` — the model writes
  deterministic logic ONCE as a small inspectable script; later runs
  re-execute it with zero model tokens (the reasonlet/metacache pattern)
  (1.21.0).
- **run(): 2,594 → 766 lines.** Config parsing, message assembly, guards
  and spawn handling extracted into cohesive modules; the 16 dispatch
  gates are an ordered pipeline with security gates marked non-ablatable
  (1.20.8 / 1.21.0).
- **Dispatch-mode prompt variant**: `brain_mode: dispatch` swaps the
  1,855-word gate prompt for a 505-word routing prompt, picked per run
  (1.24.0 / 1.24.1).
- **Stall ladder fixes**: fresh web research and fresh diagnostics no
  longer count as no-progress; a delegated-and-verified run never
  hard-stops; the bounce cap falls back to the last well-formed answer
  instead of a broken candidate (1.20.2 / 1.20.4 / 1.20.6 / 1.20.8).
- **Verification got teeth**: vacuous specialist-authored checks
  (`assert … or True`) fail review deterministically, and authored checks
  must go red→green against the pre-change tree to count as verified
  (1.20.2 / 1.22.0).
- **Spec-conflict trap closed**: docs-are-the-contract clauses +
  README/spec excerpts in coding sub-agent prompts — a specialist task
  that presumes which side is wrong IS the silent rewrite (1.22.0).

**Security & privacy**
- **Capability tier on tools**: tools declare `admin_only` on the class,
  enforced at selection/dispatch/slash, with a CI sweep that fails when a
  process-spawning tool forgets the declaration (1.23.0).
- **Knowledge stores are owner-scoped** (memory/kg/rag/pageindex) with an
  automatic one-time migration (1.20.1).
- `test.run`/`code.deps` admin-only; `test.run` firejail-sandboxed by
  default (1.20.1 / 1.24.0).
- **h5i red-team lane hardened**: SSRF guard on every URL, per-call allow
  can only narrow the operator policy, human confirmation on active-send
  verbs (1.22.0).
- `is_admin` fails closed everywhere; the role policy has a code-side
  floor; `all_owners=true` is admin-only; `/imp` checks the real role
  (1.20.6).
- Account deletion removes the account's live state; TOTP codes are
  single-use; login throttle keys username+IP; all harness git calls run
  with hooks/fsmonitor disabled (1.24.1).
- `procedure.save` went through every write gate around — now gated like
  fs.write and rejected in dispatch mode (1.22.0).

**Ops & quality**
- Admin → Status probes configured sidecars (searXNG, jev) — "configured
  but unreachable" surfaces instead of silently degrading (1.22.0).
- Prompt-overlay staleness warning (a stale custom overlay shadowed
  shipped prompts for weeks once) + guard telemetry in eval-peek
  (1.20.7 / 1.24.0).
- Docs: "life of a turn" page, generated rails registry, decision log
  (D001–D030), docs index by audience, learning-guide lessons, full
  README/screenshot refresh (1.20.3 / 1.23.0 / 1.25.0).
- CI growth discipline: complexity + prompt-size + mypy + ruff-hygiene
  baselines, and baseline GROWTH needs an explicit `baseline-bump:`
  marker in the commit message (1.20.3 / 1.20.8 / 1.24.0).
- Env rename finished: JAYNET_* everywhere, ORCH_* still dual-read with a
  deprecation warning until the drop date (1.24.0).

## Todo on fresh install

1. Try-out (throwaway, no services): clone, run `scripts/quickstart.sh`.
2. Permanent: `scripts/setup.sh` (venv, `~/.config/jaynet.env` with
   generated secrets, systemd --user units) — guided walkthrough in
   docs/setup_installation.md, fully manual path incl. multi-GPU and
   reverse proxy in docs/manual_installation.md.
3. Keep the data dir OUTSIDE the clone (`~/jaynet-data` default).
4. Models: pick from docs/models.md, then run `model.measure` per preset
   so the fit-aware scheduler has real numbers.
5. Optional extras: firejail (tool sandbox), a searXNG instance (local
   web search), a current llama.cpp build (MTP presets need it).

## Todo on update (from any 1.18.4+)

1. In the live checkout: `git pull` / `git checkout v1.25.0`, then
   restart the services. A restart marks runs in flight `interrupted` —
   deploy when quiet.
2. Reinstall deps BEFORE the restart:
   `uv pip install --python .venv/bin/python -r requirements.lock`
   (urllib3 2.8 security fix pinned; transitive deps resolve fresh).
3. Rename your env keys ORCH_* → JAYNET_* (one-line sed in
   docs/upgrading.md). The fallback still works — with a deprecation
   warning per key — until the first release on/after 2026-12-01. If you
   never did the 0.9.x rename: `orchestrator-web.service` →
   `jaynet-web.service`, `~/.config/orchestrator.env` → `jaynet.env`.
4. Automatic on first boot: existing knowledge rows are stamped to the
   first admin's owner (pageindex moves to `<data>/pageindex/<owner>`).
5. Re-run `model.measure` on your presets — RAM numbers measured before
   1.23.0 undercounted mmap'd weights (now the server process's Pss).
6. Install firejail if you want `test.run`'s default sandbox (missing
   binary degrades to a bare run with a warning).
7. Custom prompt overlay in `<data>/custom/`? Admin → Harness → Prompts
   now warns when it shadows a newer shipped prompt — diff it once.
