**Public-release milestone.** JayNet — a local-first agent orchestrator: one Python service, one web console, no containers. Local models (on the machine or the LAN) do the work; cloud models and MCP can be added and are privacy-gated. llama.cpp is the native runtime, with adopted vLLM/Ollama/OpenAI-compatible endpoints treated as local.

What 1.0.0 means: the install is documented for strangers (`scripts/quickstart.sh` for a throwaway test, `scripts/setup.sh` for a permanent install, a full manual path), the stable API contract is frozen in `docs/api.md`, CI runs ruff + the full pytest suite (1145 tests) on every push, and everything is MIT-licensed.

The highlights, if you're new: models are swappable infrastructure — the harness autoloads any configured model onto GPU/CPU mid-chat (specialists for coding/research, a different brain with `/imp`) and hands back when done, so one slot can serve many experts; a visible to-do list and replayable runs; an eval harness that turns flagged sessions into regression tests and proposals; taint-tracking privacy for cloud calls; and a studio for building/sharing skills and chains as `.jaypack` files.

Changes since 0.9.8: mobile touch scrolling no longer gets trapped by follow-to-bottom during a run; housekeeping (todo-file sweep, README polish).
