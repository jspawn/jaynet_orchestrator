# JayNet v1.31.0 — admin IA: build, operate, measure

An admin-console release: the information architecture now follows one
rule — **Studio = things you build, Harness = settings of the machine,
Eval = measurement** — plus a pile of UI bugs flushed out while moving
the furniture. All gates green.

## The split

"Studio & Eval" becomes two top-level tabs:

- **Studio** — Build (skills/chains/connectors/tools editor), Connectors
  (state, read-only/read-write mode, test, import/export — moved here
  from Harness → Integrations, finally next to the editor), Plugins.
- **Eval** — Cases, Results, Proposals, Benchmark.
- **Harness** keeps Runtime, Prompts, Tools, Data; the old Integrations
  subtab shrinks to MCP servers. Old `#connectors` / `#plugins` /
  `#integrations` hashes redirect.

## Connector management fixes

Found while wiring a live ERP demo connector: the read-only/read-write
dropdown and the enabled toggle silently 422'd (fetch sent JSON without
a content-type header — fixed centrally in the `api()` helper), the
Studio import picker hid `.jayconn` files the backend installs fine, and
Integrations promised an import with no button. All fixed; the dropdown
now says what it does ("read-only · write tools off" / "read-write ·
writes ask in chat").

## Config-reset tombstone

Resetting an override whose key never existed in runtime.yaml wrote a
`None` tombstone into the live config and crashed every auto-mode run
(selector iterating `keyword_namespaces`). Resets now delete such keys;
the selector tolerates `None` regardless. Regression tests on both ends.

## Measured negative: exact-args prompt rule

A gate-prompt line against BFCL param over-specification was A/B'd on 30
deterministic cases: McNemar p=1.0, target cases failed identically.
Reverted, budget reclaimed. Not every hypothesis survives contact —
that's what the harness is for.

## Admin SPA extraction

admin.html's inline CSS/JS is now `admin.css`/`admin.js` (4,799 → 1,067
lines of markup). Browser-cachable per asset; the static-JS guards and
the cache-buster tripwire cover the new files.

## Upgrade notes

- No config changes needed. Old admin bookmarks redirect.
- If you run a reverse proxy with an admin-HTML cache, force one refresh
  after deploy (the page references the new `admin.js`/`admin.css`).
