# v1.4.0 — the harness enforces its own doctrine

2026-08-26 · Feature release. This cycle's theme: things the prompt used to
*hope for* are now *mechanisms* — delegation, strategy change on crash
loops, reasoning budgets — plus real toolchains for `code.run` and the eval
forensics a live full-suite run demanded. No breaking changes.

## Highlights

- **Devbox: `code.run` can compile the world, not just the host.** Opt-in
  per-run rootless podman containers (rust, go, node, C/C++, Java, Python,
  **.NET 8 + 10** on an Ubuntu base) replace the host-limited firejail
  sandbox. Same confinement shape (only the run's workspace + tmp mounted),
  shared cargo/go/npm/nuget caches so iterative builds stay fast, idle
  containers reaped — and the network is cut **live** the moment a run
  touches private data, not just on the next container. Podman or image
  missing → silent fallback to firejail with a note.
- **Delegate gate** — the harness insists on delegation, not just suggests
  it. After `loop_guard.delegate_nudge_after` (default 3) inline code edits
  with delegation available but unused, the tool result carries a
  delegate-to-the-specialist directive; `delegate_enforce: true` *rejects*
  inline edits from the threshold on. The gate only engages when delegation
  actually routes somewhere stronger (configured coder alias or live
  coding-strength specialist), and any `code.delegate` call disarms it —
  single-model installs and verify-fix loops stay untouched.
- **`council.vote`** — self-consistency for small local models: sample the
  same single-answer question N times at temperature, majority-vote the
  extracted answers. Failed samples abstain, ties are reported not picked,
  every sample charged to the run budget, cloud gate mirrors
  `council.debate`.
- **`agent.fanout`** — map/merge parallelization: N independent subtasks as
  concurrent sub-agents (all of spawn's guarantees), distilled reports
  merged. Partial failure is signal, all-failed is an error. Same-GPU
  children serialize — the description says so.
- **Strength routing everywhere.** Presets declare capability tags
  (`coding`, `security`, …) registered with meanings in `models.strengths`;
  one shared resolver routes `code.delegate`, `agent.spawn` and fan-out
  children to the live specialist providing the tag. Tagged-but-stopped
  returns an actionable `model.ensure` error; the prompt carries a live
  directory of tags and holders.
- **Reasoning discipline.** `REASONING_BUDGET` (→ `--reasoning-budget`,
  shipped 4096 on brain presets) force-closes the think block so the reply
  always has room inside the completion cap; a turn cut at the cap
  mid-reasoning gets one nudge instead of ending as an empty "ok";
  consecutive identical crashes get a strategy-change escalation
  (`loop_guard.failure_nudge_after`, default 3).
- **Eval forensics.** The judge sees the complete per-turn tool list
  (trajectory truncation could fake "skill never loaded"), falls back to
  `local-specialist` on HTTP-200 garbage (OpenRouter autoroute can return
  non-raising junk for `json_object`), budgets 12k tokens with
  `finish_reason` capture; cases get a wall-clock ceiling
  (`eval.turn_wall_clock_s`, default 1800) for zero-cost stuck runs; new
  deterministic `delegate-strength-routing` case; benchmark variants pick
  **full harness vs brain only** for clean A/B.
- **Skill pinning.** "Use the j-space skill" in chat force-loads the skill
  mechanically — conservative matching, plain mentions untouched.
- **Ops.** `local_concurrency` defaults 1 → 4 (matches llama.cpp's
  `n_slots=4` with unified KV); LiteLLM request timeout 120 s → 600 s;
  pytest is a core dep; the workspace prompt teaches the uv doctrine;
  `web.fetch` extracts main content via trafilatura (local — nav/footer
  boilerplate no longer eats the content cap, URLs stop leaving the box);
  gate prompt diet (only what the model can act on).

## Upgrade

Pull, `uv pip install -r requirements.txt` (trafilatura + pytest are new
core deps), restart both services. Optional: build the devbox image
(`scripts/devbox-build.sh`, ~3 GB) and set `tools.code.devbox.enabled:
true`; set `loop_guard.delegate_enforce: true` if coding should *always*
hit the specialist. Note: `REASONING_BUDGET` ships on the brain presets and
needs a recent llama.cpp build (b10380+ verified — older builds fail to
start on the unknown flag; clear the key there). Re-run `bench.import` to
regenerate existing tb-* cases with the self-bootstrapping checker.
