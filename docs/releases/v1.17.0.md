# v1.17.0 — 2026-10-01

Minor release: JayNet learns to speak and to navigate long documents.
Two new plugins — **omnivoice** (local text-to-speech with voice design
and cloning) and **pageindex** (vectorless, reasoning-based retrieval
over long PDFs) — plus `read-aloud`, the first chain that switches
models mid-pipeline, and a lifecycle fix that stops generated artifacts
from piling up on disk.

## omnivoice — local text-to-speech

`audio.speak` turns text into a WAV on your own GPU — 600+ languages,
voice design via natural-language `instructions` ("afraid, whispered,
hurried"), non-verbal symbols like `[laughter]` — and `audio.clone`
registers a cloned voice from a reference WAV + exact transcript. The
backend is [OmniVoice](https://huggingface.co/k2-fsa/OmniVoice) on
[omnivoice.cpp](https://github.com/ServeurpersoCom/omnivoice.cpp)'s
OpenAI-compatible `tts-server` (llama.cpp-style GGUF infra; the helper
repo builds it with `./build_tools.sh omnivoice rocm`). Same shape as
imagegen: lazy start, keep-warm reaper, WAV staged as a download and
mirrored into the run workspace, shutdown hook. No slot hibernation —
the Q8_0 pair is ~1 GB and fits next to brain + specialist.

- **GGUF auto-discovery:** `plugins.omnivoice.model`/`codec` left empty
  pick up the first `omnivoice-base-*.gguf` / `omnivoice-tokenizer-*.gguf`
  in the standard model dir — a quant swap is a file drop, not a config
  edit.

## pageindex — vectorless tree index for long PDFs

Wraps the [pageindex](https://pypi.org/project/pageindex/) SDK (MIT):
`doc.index` builds a persistent hierarchical tree index of a long
document with a local model (through the JayNet LiteLLM proxy — nothing
leaves the box), `doc.tree` shows section titles/summaries/page ranges,
`doc.pages` reads exact pages. The brain reasons its way down the tree
instead of retrieving similarity chunks — for reports, contracts and
manuals too long to read inline, and repeat questions over the same
document. `doc.extract` and the long-document skill stay right for
short docs. Verified live against a real index run (SDK shapes pinned:
`page_index` page keys, `pageNum` meta lookup).

## read-aloud — the first model-switching chain

`chains/read-aloud.yaml`: step 1 loads the creative-writing preset into
the specialist slot via `model.use` (default `hemmingway`, graceful
degradation when missing), step 2 splits the text into mood-tagged
chunks on that model — per-chunk voice instructions are the only way
emotion can *shift* mid-text — step 3 voices each chunk with
`audio.speak` and stitches the WAVs into one `reading.wav`. A new
static gate validates every shipped chain in CI.

## Fixes

- **imagegen/omnivoice: server-side artifacts no longer pile up.** The
  backend's own copy in `<data>/images/` / `<data>/audio/` was redundant
  once the download bundle was staged but stayed on disk forever. Both
  plugins drop the original on successful staging and keep it only when
  staging failed.
- **docs: doubled tab-path sweep.** The v1.16.1 tab-rename pass left
  "Admin → Studio & Eval → Studio & Eval → …" in 9 markdown files.

Upgrade notes: `pip install pageindex` into the venv if you want the
pageindex plugin; omnivoice needs the `tts-server` build + ~1 GB GGUFs
(plugins/omnivoice/README.md). Both plugins ship disabled — enable in
Admin → Harness → Plugins.
