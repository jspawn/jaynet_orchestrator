# JayNet v1.15.0

Feature release. A new champion brain, a fix for a failure mode every
specialist was paying for, and the routing sidecar grew up. Full notes:
`docs/releases/v1.15.0.md`, code-level map: `docs/code-map.md`.

## Highlights

**The brain search has a winner — by measurement, not vibes**

- **Cyber-Tiel-35B-A3B** (routing-trained MoE, ~3B active params,
  ~106 tok/s) took the fourteen-candidate bakeoff at **38/41** with the
  first **terminal-bench clean sweep (10/10)**.
- The headline is delegation health: 81% of specialist hand-offs were
  chosen by the brain itself — the "models won't delegate" problem
  solving itself. First `ask-user` pass in any recent era, too.
- Table, per-case grid and 23 lessons: `docs/brain-bakeoff.md`.

**Wrap-up stall rungs — "verified done" now closes the run**

- Once a delegation returns the deterministic `verified` flag, the stall
  ladder swaps "produce a deliverable NOW" for "the work is DONE — write
  your final answer". The old advice fed todos-rewrite loops until the
  iteration cap.
- Validated live: `code-bugfix` FAIL→PASS (443s→216s, 21→7 iterations)
  and `code-spec-conflict-trap`'s **first pass in any era**.
- Found by the flash-coder specialist A/B (turbo keeps the slot, 10/11
  vs 8/11 — no wrong-code failures, ~2x tokens per case).

**jevify routing sidecar is managed infrastructure**

- `plugins.jev` with `manage_sidecar` + a probed recipe registers jevify
  with the process manager: boot start, crash auto-restart, clean
  shutdown, `~/.local/bin` PATH fallback for systemd units.
- Route bench: jevify over the specialist hits **63.4%** routing
  accuracy (p50 0.98s); keywords manage 13.2%.

**Quality of life**

- Chat renders deliverables **inline** — images/SVG as images, PDF/HTML
  sandboxed — instead of download-button-only.
- imagegen ships a skill + keyword namespace: "draw me…" finds
  `image.generate` without a manual `skill.load`.
- New **mermaid skill**: render-and-verify diagrams with mermaid-cli,
  exportable as `.jaypack`.
- Developer onboarding: `docs/code-map.md` (which mechanism lives in
  which file) + a mermaid architecture diagram in the README.

**Security maintenance**

- pyjwt 2.13.0 → 2.14.0 (10 CVEs), oauthlib 3.3.1 → 4.0.0 — both flagged
  by CI pip-audit, all three lockfiles audit clean.

## Upgrading

Pull, restart the two services, done. If you run the jev plugin and want
the managed sidecar: set `plugins.jev.manage_sidecar: true` and
`plugins.jev.recipe` to a probed recipe file — JayNet owns the process
from the next boot.
