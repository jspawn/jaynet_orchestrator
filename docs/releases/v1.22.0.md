# v1.22.0 — audit hardening round: procedures gated, red→green checks, sidecar liveness

Minor release on 1.21.0. Closes the 2026-10-10 audit findings and three
items from the still-open ledger. No config migration; one behavior
tightening to know about (h5i loopback refusal, below). 2,316 tests
green; all gates clean.

## procedure.* joins the write gates

`procedure.save` bypassed every write gate — in dispatch mode the brain
could write AND run its own code via save+run, the exact route
`brain_mode: dispatch` exists to close. Now: save is write-like for the
delegate/strength/j-space gates, rejected outright by the dispatch gate
(`procedure.run` stays open as the verify lane), and requires human
confirmation like `fs.write`/`code.patch`. `procedure.run` validates the
procedure slug before reading (a `../`-style name read files outside the
workspace).

## Authored checks must go red→green

A specialist-authored `CHECK:` command green on the post-change tree is
no longer enough: on git-backed workspaces it also runs against a
detached worktree at the pre-spawn ref (new check files overlaid,
modified files keep old content). Green on both sides = never
discriminated the change → `verified` flips False. Non-git workspaces
keep the old verdict with a `baseline_note`.

## h5i lane hardening

Four holes closed: SSRF guard on `browser.browse` open/read and websec
`socket`/`grpc` direct-dial URLs (same helper as the core web.* tools —
loopback/link-local/metadata refused, LAN allowed); per-call `allow` may
only NARROW `plugins.h5i.allow`; active-send verbs (recon `paths`;
websec `replay`/`experiment`/`matrix`/`sequence`/`socket`/`grpc call`)
ask for human confirmation; `browser.browse` is now `private` (its
requests/audit/screenshot verbs expose captured credentials).

**Behavior note:** h5i browsing to `127.0.0.1`/`localhost` is now
refused, matching `web.fetch` policy. LAN addresses (e.g. a searXNG on
the local network) are unaffected.

## Sidecar liveness on the Overview card

`/api/admin/status` auto-probes configured sidecars — searXNG
(`tools.web.search_endpoint`) and a local jev backend — so "configured
but unreachable" surfaces instead of being absorbed by fallback chains
(the searXNG-dead-for-7-days post-mortem). `web.services` entries are
deduped by URL.

## Spec-conflict trap: docs reach the specialist

Trace-dig of `code-spec-conflict-trap` (3 consecutive fails): the brain
surfaced the spec/test contradiction, then delegated "fix pricing.py" —
and the specialist never saw the README. Three layers: the gate prompt's
conflict rule now covers delegation explicitly; the coding worker prompt
gains a docs-are-the-contract clause; coding sub-agent prompts carry
PROJECT DOCS excerpts (root README/spec/design/RFC,
`tools.code.repomap.docs_chars`, default 1500, 0 disables).
