# v1.13.0 — 2026-09-22

## Brain tool gating, full version: dispatcher mode

`tools.code.brain_mode` gains a third value, `dispatch` (superset of
`verify`). With a coding specialist present, the brain's own
`fs.write`/`fs.edit` calls into **source files** (~50 extensions plus
extension-less build files like Dockerfile/Makefile) are rejected pre-exec
from the first turn — no threshold, no nudge. Prose, config and data files
stay writable; one `specialist.delegate` call disarms the gate. Tool
descriptions state the rejection at the decision point.

This is the field's consensus fix for the "orchestrator does the work
itself" failure mode (see `docs/brain-bakeoff.md`, lesson 6): don't
persuade the model, remove the capability. `verify` stays the shipped
default; single-model installs are untouched.

## Audit #22 fixes (1 C, 5 D)

- **jev privacy gate (C1/D4):** the `route_request` hook fires at run
  start, before the run's taint/approval machinery exists — with the
  openrouter backend every request's text would have left the box. The
  hook now refuses the cloud backend unless
  `plugins.jev.allow_cloud_route: true` is set explicitly, and `route`
  defaults to `false` in code, matching the recorded "stay keyword"
  decision. `runtime.yaml` seeds the section; new tests prove no network
  call happens without the opt-in.
- **Dispatch wording fix:** the first live dispatch run showed "Source
  files are REJECTED" over-generalizing in a small brain to "files are
  rejected" — it stopped writing anything, including the plain-text
  deliverables the gate allows. Descriptions now lead with what stays
  writable (deliverables, notes, configs, data) before naming the
  source-code rejection.
- **Hygiene:** chat asset cache-bust bumped (v42 → v43 — card expiry,
  delegation feed pinning and the task clamp were stuck in browser
  caches), catalog regenerated (11 plugin tools, `jev.decide` row),
  plugin enumerations updated to four builtins across playbook/README/
  learning guide, stale version strings fixed, screenshots re-shot
  (28 PNGs).

## Upgrade

No schema or config migrations. To opt into dispatcher mode:
`tools.code.brain_mode: dispatch` (admin → Config), effective per run —
worth it when a coding specialist slot is loaded and the brain keeps
implementing inline.
