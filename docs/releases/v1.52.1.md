# JayNet v1.52.1 — sandbox, privacy and schedule hardening

This security patch closes a reproduced Python-sandbox data disclosure and
same-origin preview execution paths, then tightens outbound privacy and
unattended approvals.

## Sandbox and file previews

- Python Firejail execution now whitelists only its work directory, explicit
  workspace/artifact/subcall paths and the configured Python venv. Other data,
  including `users.db`, chats and uploads, is no longer readable through
  `code.run` Python mode.
- Inline file previews use the explicit `_PREVIEW_MEDIA` allowlist everywhere.
  Unknown suffixes such as `.shtml`, `.xhtml` and `.xht` download as
  `application/octet-stream`; HTML/SVG previews retain the CSP sandbox.

## Private-data egress

After private tool results, cloud LLM and `web.*`/`browser.*` calls require
explicit privacy approval. This includes GET/HEAD and runs with admin
auto-confirm enabled. `share_private` remains the blanket opt-in.

## Scheduled approvals

Admin schedules have a new comma-separated **unattended tool approvals** field,
stored as `auto_approve_tools`. Only those named tools auto-confirm on each
firing. Empty and legacy entries decline every gated tool; non-admin schedules
always decline them. Global `tools.schedule.auto_confirm: false` disables the
allowlists too.

**Review existing schedules after upgrading:** any unattended `job.start`,
`ops.run`, `git.push`, or other gated tool must now be named explicitly.

## Smaller fixes

- `ops.run` catches off-box `--url=`/`--proxy=` forms and rejects arbitrary
  executable paths impersonating an allowlisted basename.
- Backup codes are consumed atomically; slow 2FA operations run off the event
  loop. Ownerless jobs are hidden, and API-token `last_used` writes are limited
  to once per minute.

## Verification

2,907 tests pass, including a real Firejail data-disclosure regression and
concurrent backup-code consumption. Ruff, mypy, complexity, prompt budgets,
generated docs/rails, dependency audits, ShellCheck and diff hygiene pass.

## Upgrading from v1.52.0

No dependency or database migration is required:

```bash
git fetch --tags
git checkout v1.52.1
systemctl --user restart jaynet-web
scripts/orch --doctor
```

Review existing admin schedules and configure only the tools they genuinely
need unattended.
