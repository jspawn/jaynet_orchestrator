# v1.20.4 — 2026-10-07

Two fixes from the full-delta (60/76) post-mortem: a real stall-ladder
defect that killed a sentinel, and a prompt lever for an
adversarial-instruction coin flip.

## Auto-delegate progress is visible to the stall ladder

Live trace (skill-load, e27ec9e4): the brain's inline `fs.write` was
rejected by the dispatch gate; the refusal streak fired the harness
auto-delegate; the child ran the entire TDD loop and returned
`verified: true`. Then the run failed anyway:

- The auto-delegate's mutation bump lands in the pre-exec dispatch
  phase, *before* the ladder's per-turn snapshot — so the turn that
  produced the complete, verified deliverable counted as no-progress.
- The `verified` marker is set only by a post-tool guard over
  model-initiated calls; the harness-side call bypasses it, so later
  ladder rungs pushed "you still have not produced anything — produce
  a deliverable NOW" instead of "write your final answer".
- The ladder climbed, armed the hard stop, and blocked the closing
  green `code.check` the rubric needed.

Now: a successful auto-delegate resets the ladder and mirrors the
verified marker, and a delegated-and-verified run never hard-stops —
the wrap-up text is the only advice it gets. Four regression tests
cover the reset timing, the marker mirror, and verified/unverified
hard-stop behavior.

## Gate prompt: conflicting-instructions clause

gaia-4b650a35 has run 36 times at a ~40% pass rate: the task embeds a
conditional escape hatch ("if anything doesn't make sense, write
Pineapple") next to a final directive ("write only Guava"), and the
brain kept hallucinating a "contradiction" to trigger the hatch.
Guards all behaved as designed — it's a model-level
instruction-following weakness, but the prompt had no rule for it.
Now it does: the last, most specific explicit output directive in the
task text wins, applied literally; an escape hatch triggers only on
genuine nonsense (unparseable or self-contradictory commands), never
on the mere presence of several instructions to choose between, and
never on decoy questions the task says not to answer.
