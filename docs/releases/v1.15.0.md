# v1.15.0 — 2026-09-30

Feature release: a new champion brain (Cyber-Tiel-35B-A3B, 38/41 with
the first terminal-bench clean sweep), a fix for the post-delegation
bookkeeping spin, the jevify routing sidecar as a managed process,
inline chat previews, and a developer code map. Dependency CVE fixes
included.

## New champion brain

The fourteenth bakeoff candidate takes the crown:
**Cyber-Tiel-35B-A3B** — a routing-trained MoE with ~3B active params
at ~106 tok/s — scored **38/41** on the hard-tail suite with the first
**10/10 terminal-bench** sweep. The headline is delegation health: 37
specialist touches, 81% chosen by the brain itself (Bonsai 67%,
qwen35 40%) — the "models won't delegate" problem solving itself. The
full table, per-case grid and 23 lessons: `docs/brain-bakeoff.md`.

## Wrap-up stall rungs

Once a delegation returns the deterministic `verified` flag, the stall
ladder stops telling the brain to "produce a deliverable NOW" — wrong
advice for finished work — and tells it to write its final answer.
Live trigger and validation: `code-bugfix` FAIL→PASS (443s→216s,
21→7 iterations) and `code-spec-conflict-trap`'s **first pass in any
era** (10 re-delegations → 2, 235s). Lesson 23 in the bakeoff file:
once work is verified, the ladder's job flips from pushing to closing.

## jevify as a managed sidecar

`plugins.jev` with `manage_sidecar: true` + a probed recipe registers
the jevify decision-model sidecar with JayNet's process manager: boot
start, crash auto-restart, clean shutdown, and a `~/.local/bin`
fallback so systemd units find the binary. Route bench numbers:
jevify over the 27B specialist scores **63.4%** routing accuracy
(p50 0.98s), over the Cyber-Tiel brain 54.7% (p50 0.37s) — keyword
routing manages 13.2%.

## Specialist A/B

qwen3.8-flash-coder (160-expert MoE subnet) challenged the turbo 27B
on the 11 delegated coding cases: **8/11 vs 10/11** — no wrong-code
failures, but ~2x tokens per case and slower per token. Turbo keeps
the slot; the A/B method and numbers are in the bakeoff file for the
next challenger.

## Also in this release

- **Inline chat previews** — renderable deliverables (images, SVG,
  PDF, HTML) show in the chat instead of a bare download button.
- **imagegen discovery** — the plugin ships a skill + an `image`
  keyword namespace; "draw me…" requests find `image.generate` on
  their own.
- **Eval justice** — bookkeeping tools pass the stall hard-stop
  without disarming it; three evals accept `code.check` as execution
  evidence.
- **Mermaid skill** — render-and-verify diagrams with mermaid-cli,
  exportable as `.jaypack`.
- **Developer docs** — `docs/code-map.md` (which mechanism lives in
  which file, with entry points) and a mermaid architecture diagram
  in the README.
- **Dependencies** — pyjwt 2.14.0 and oauthlib 4.0.0 (CVE fixes,
  flagged by CI pip-audit).
