# v1.2.0 — RLM, public benchmarks, and a grown-up code.execute

2026-08-23 · Feature release. Three threads land together: the RLM pattern
(Recursive Language Models) goes native, public agent benchmarks become
first-class eval cases (including near-official Terminal-Bench runs in
containers), and `code.execute` gains a persistent workspace, container
bash, and spill-safe output. No breaking changes.

## Highlights

- **RLM, natively** ([arxiv.org/abs/2512.24601](https://arxiv.org/abs/2512.24601)):
  context-as-variable without a second, unmediated agent loop. `code.execute`
  snippets get mediated `llm_query` / `llm_query_batched` subcalls (per-run
  unix socket, per-execution grants, budget-billed, taint-gated local-only,
  traced), plus the new `context.stage` tool and an RLM-first rewrite of the
  `long-document` skill. Kill switch: `tools.code.subcalls.enabled: false`.
- **Public benchmarks as eval cases** — the eval schema grows two
  deterministic grading keys (`expect.answer_exact_any`, GAIA-scorer exact
  match; `expect.checker`, an in-sandbox grading script), and the new
  opt-in **benchlab plugin** imports Terminal-Bench and GAIA Level-1 as
  custom eval cases. TB comes in two modes: *lite* (curated container-free
  subset) and *full* (rootless podman: per-task images, `code.execute`
  inside the container, the task's own tests grade in-container — close to
  the official protocol). Suite runs, judge, statistics and Benchmark
  compare work on them like any other case.
- **`code.execute` grows up** — a persistent per-run workspace
  (`ORCH_EXEC_WORK`: files survive across calls, visible to
  `fs.*`/`deliver.files`), `language: "bash"` in container runs, and
  truncation that spills full output to a file instead of dropping it.
  Also fixes a latent sandbox bug: firejail `--read-write` binds under /tmp
  were hidden by `--private-tmp`, silently breaking artifact delivery in
  eval runs (now `--whitelist`-companioned).
- **Hardened after audit** — container mode is enforced eval-runner-only
  (a static `tools.code.container` in runtime.yaml is stripped at load),
  image builds fail cleanly when pytest can't install, and spill files
  stay out of the deliverables list.
- **Also in this window:** Jay's Studio packs (28 MIT thinking-skills as
  importable `.jaypack` files in a side-repo, docs/studio-packs.md), fresh
  docs + screenshots.

## Upgrade

Pull, restart, done. Subcalls are on by default; benchlab stays disabled
until you enable it (Admin → Plugins). GAIA import needs your own
`HF_TOKEN`; TB full mode needs rootless podman.
