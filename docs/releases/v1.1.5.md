# v1.1.5 — j-space skill, run badges, gate nudge

2026-08-21 · Patch release: deliberate-workspace doctrine ships as an
on-demand skill, with a live run badge, two guarding evals, and a
complexity-gate nudge toward it. No breaking changes.

## Highlights

- **New skill: j-space** — an adapted vendoring of the Apache-2.0 J-Space
  Cognition Suite V3.6 (prompt doctrine, NOT the interpretability research
  it borrows vocabulary from — nothing here reads model internals). The
  brain classifies a task **fast / full / loop**, loads only the module
  the task earns, plans before editing, and keeps a
  `.jspace/WORKSPACE.md` ledger of settled/open/next on long work — state,
  not a task list; the plan stays in the visible todo list, pinned via
  `context.pin` for compaction survival. Modules and references ship
  verbatim; `LICENSE` / `THIRD_PARTY_NOTICES.md` / `NOTICE` ride along in
  the skill directory, and the root notices file credits the suite.
- **New core tool: `run.badge`** — a short live status label on a run,
  shown in the chat footer line and the debug view (Ctrl+D), replayed with
  saved chats. Skills use it to show which mode is active; j-space badges
  `j-space: full` / `j-space: loop` at the gate and on every pass change.
  Registered in the core toolset including the trivial-message minimal
  set, so a skill loaded mid-run can always badge.
- **Complexity gate nudges toward j-space at 3+.** Deliberately a nudge,
  not an auto-load: the skill's gate only works when the model classifies
  the task itself, and its own doctrine forbids loading machinery the task
  didn't earn. Default-on was rejected for the same reason — it would tax
  the fast path and dilute the gate prompt.
- **Evals:** two new cases — `j-space-loop` (multi-file rename driven
  through the loop pass: plan-before-edit, badge, tests actually run) and
  `j-space-floor` (a "quick, no ceremony" request that isn't fast must be
  escalated, not answered from the request alone).
- **Audit closure:** eval graph prebuild subprocess env now goes through
  `scrub_env` (same posture as the MCP stdio bridge); release notes for
  v1.1.3/v1.1.4 backfilled.

## Upgrade

Pull, restart, done. j-space costs nothing until loaded — say "use the
j-space skill" on a hard task, or let a 3+ complexity rating nudge it.
