# v1.5.2 — audit #10 closure

## Fixes

- **Connector SSRF guard resolves DNS now.** The v1.5.1 guard checked
  link-local IP literals at pack load, but a pack-supplied *hostname*
  resolving to 169.254.x slipped through — the one credential-theft vector
  the guard exists for. The request path now resolves the host and refuses
  when ANY address is link-local (IPv4-mapped IPv6 unwrapped), mirroring
  the web tools' posture with the connector policy: loopback and RFC1918
  stay allowed — homelab mail servers and ERPs live there.
- **The `| check:` trust surface is named and bounded.** `docs/security.md`
  documents the unattended execution of a goal's check command beside the
  schedule auto-confirm entry (same trust shape: the command string is
  parsed only from the user's own slash message — prompt injection cannot
  reach it). And `goal.check_timeout_s` floors to the 120 s default on
  0/unset — there is no unbounded mode.
- Playbook coverage line caught up to its own body (v1.5.1 features).

Pull, restart both services. Nothing to configure — connector packs and
