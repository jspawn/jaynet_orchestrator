# JayNet v1.34.0 — harness experiments + scoped Caveman Compression

## Harness experiments

Admin → Eval → Experiments contrasts a scripted eval case across four matched
arms: baseline, invariant candidate, domain candidate and composed overlay.
Prompt, skill, tool-description and selected config edits stay run-scoped;
ordinary eval results and live artifacts remain untouched. Nothing becomes a
proposal without an explicit admin action, and proposals remain pending until
the usual accept step.

## Caveman Compression

`runtime/caveman.py` adds generation-time compact-language instructions for:

- hidden reasoning, only when thinking is enabled;
- outgoing delegation tasks and child reports;
- agent-loop LLM calls, subcalls, council panels and delegation reviews.

User-facing answers, direct slash-command output, code, JSON, commands and
verbatim evidence stay outside the compression scope. This is not post-hoc word
stripping. Compactness and token savings remain model-dependent; no live A/B
saving is claimed in this release.

## Upgrade

The experiment table is created automatically. `config/runtime.yaml` enables all
Caveman scopes; a legacy config without the `caveman` section keeps the feature
off. Hard-refresh the admin console once (`admin.js?v=7`).
