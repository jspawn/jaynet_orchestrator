# JayNet v1.45.2 — audit and verification hardening

This patch release closes the new audit findings and two pieces of long-standing
verification/tool-timeout debt. No runtime behavior changes beyond the tool
wrapper limits.

## Fixes

- Declare `ModelClientMixin.config`, so both strict-template call sites pass
  mypy directly; no new baseline entries were added.
- Admin static checks require numeric JS/CSS cache busters rather than literal
  version values, preventing the next asset bump from turning the suite red.
- The scratch-directory cleanup regression invokes the captured temporary
  directory's finalizer explicitly instead of depending on GC timing under
  xdist. It passes 20 consecutive py3.11 repetitions.
- `audio.speak: 660` covers OmniVoice's 300-second health wait plus 300-second
  generation budget. `doc.index: 0` lets the one-time, persistent whole-document
  indexing pass finish instead of abandoning it at the generic 180-second cap.

## Documentation

The screenshot sweep was rerun against the live console. It includes the
priority-based preset catalog, benchmark allowed-presets, current model servers,
account pages, chat and login views; sensitive user content remains redacted.

## Verification

- Full test suite passes, including the new timeout and cleanup regressions.
- Ruff, mypy, complexity, hygiene, prompt, docs/catalog, shellcheck and diff
  gates pass.
- All three dependency lockfiles report no known vulnerabilities.
- The py3.11 cleanup regression passes 20/20 repetitions.

## Upgrading

Pull and restart both services:

```bash
systemctl --user restart jaynet-web litellm-proxy
```

Existing presets and stores need no migration.
