# v1.14.1 — 2026-09-24

Patch release on v1.14.0: two live-found harness bugs (both pinned with
regression tests), preset archiving, and the ZDTaichu5.0 chat template.

## Fixes

- **devbox: the reaper no longer kills fresh containers.** Two stacked
  bugs produced `no such container` ghosts ~30s into fanout runs (39
  hits in one delta, cost an eval case): podman's `StartedAt`
  (`… +0200 CEST`) never parsed with `fromisoformat`, so the orphan
  sweep's young-container guard NEVER fired and every stateless box was
  stopped on sight — and `ensure()` wrote the state file only *after*
  `podman run` returned, handing a concurrent sweep exactly such a
  stateless box. Timestamps now parse (named zone stripped;
  unparseable fails safe = never stop) and the state file is pre-booked
  before the container starts.
- **loop: rewrite loops can't hide from the stall ladder anymore.** A
  byte-identical repeat of an earlier *successful* call (live: 45× the
  same fs.write over 20+ minutes) slipped both rails — `repeat_blocked`
  only tracks error repeats, and each success re-bumped the mutation
  generation, resetting the stall ladder (and the duplicate guard's
  window). Identical twins of earlier OK calls now count as
  no-progress; distinct mutations still reset, so edit→test cycles are
  unaffected.

## Features

- **Presets can be archived** (Admin → Presets → archived checkbox).
  Tag-based swap routing picks the FIRST strength-tag holder in dict
  order, live or not — a retired preset with duplicate tags hijacked
  `coding` swaps live. Shelved presets stay listed (greyed + pill),
  never route, and `model.use` refuses them with a clear error.
  Reversible, unlike deletion. Archiving affects selection only — a
  running model keeps serving until stopped.

## Assets

- **`presets/chat_templates/zdtaichu5_tools.jinja`** — ZDTaichu5.0
  (qwen3.5 family) template that renders mid-history system notes
  inline instead of raising (same fix family as qwen3.6_tools.jinja);
  required for brain use, or the first guard nudge kills the run.

## Upgrade

Pull, restart `jaynet-web`. The presets DB migrates itself (new
`archived` column, default 0). No config changes required.
