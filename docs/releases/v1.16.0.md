# v1.16.0 — 2026-10-01

Feature release: the admin console is reorganized from 16 flat tabs into 6
top-level tabs with subtabs, the h5i plugin becomes a red-team browser with
recon/websec tools, stalled and capped runs end gracefully with a synthesis
turn, and the chat roll gets attachments that persist, tool-call grouping,
a lightbox, and clickable bare URLs. Plus a report-only update check for
external components, the imagegen workspace fix, and CVE bumps.

## Admin console

- **16 flat tabs → 6 top-level tabs with subtabs.** **Status & Usage**
  (Overview / Usage / Recent runs), **Models** — the model-switching config
  in one place (Servers / Presets / Files / Cloud), **Harness** (Runtime /
  Prompts / Tools / Integrations / Plugins / Data & Backup), **Studio &
  Eval** (Studio / Eval / Results / Proposals / Benchmark), **Flagged
  Chats**, **Users**. Pure reorganization: sections byte-identical, all
  element ids preserved, `#<top>/<sub>` hash routing with redirects for all
  16 old hashes, tab bars scroll with an edge fade, grids stack below
  900px. docs/admin.md restructured to match; the screenshot script walks
  top tab × subtab and the whole PNG set was regenerated (12 stale files
  deleted).
- **Update check (Status → Updates card).** Report-only installed-vs-
  upstream comparison for h5i (GitHub), jevify (PyPI), the litellmenv proxy
  venv (against the lock pin), and the registered llama.cpp binaries
  (walks releases for the newest `b####` tag — `/releases/latest` can point
  at an asset-less tag). Each row carries the upgrade command; nothing
  auto-updates. 24h cache, **Check now** forces a probe; `updates.enabled`
  config section (default on).

## h5i 0.2.0 — the red-team browser

- `browser.browse` gains `submit`, `scroll`, `waitfor`, `structured`
  (JSON-LD/OpenGraph/meta — property portals publish listings there),
  `transcript`, `screenshot` (optionally shown to a vision brain), `audit`,
  and `capture: true` on `open`. The description, plugin README and
  docs/plugins.md carry the red-team workflow with scope discipline:
  authorized targets only, no complete PoC no vulnerability.
- **browser.recon + browser.websec** join when the h5i recon/websec plugin
  binaries are installed: an endpoint ledger (candidate vs confirmed is
  h5i's honesty discipline) and the HTTP workbench (replay with mutations,
  diff, match, findings with message-id evidence). Both `private` — raw
  captures carry credentials, results stay in the box.
- **`on_run_end` plugin hook + session reaping.** The hook fires once per
  run on every terminal path; h5i closes the run's browser session from it
  (the model almost never calls `close` — ~80 stale sessions had piled up
  live).

## Graceful endings

Live trigger: a research child found the right portal URLs, got two fetches
blocked by the stall hard-stop, then died at its 8-iteration cap returning
"(no answer produced yet)".

- Stall hard-stop escalates to a tools-off **wrap-up turn** when
  auto-delegation can't salvage the run; wrap-up/churn labels are
  gate-neutral ("refused tool calls").
- **`agent.final_synthesis` (default on):** a run killed by `max_iterations`
  after gathering material gets one final no-tools turn — findings plus a
  "what's unverified" list, marked `[Partial — iteration budget exhausted]`.
- **`agent.default_sub_iterations` 8 → 16** (ceiling, not target); spawn/
  delegate arg descriptions tell the brain to budget research-shaped tasks
  explicitly.
- Synthesized partials survive the cut-off envelope with a roomier cap
  (4000 vs 1500 chars) and continue-oriented advice.
- Near-dup guard respects lane-switching boolean flags — the
  `web.fetch js=true` retry the 403 hint advises is no longer blocked as a
  near-duplicate.

## Chat roll

- **Attachments persist in turns** (`atts` through the client snapshot,
  `TurnModel`, new `chat_turn.atts` column) — an image posted with + now
  survives reload, other devices, and saved chats.
- **Consecutive same-tool rows group** into one expandable "×N" row with an
  error tally; chains are tighter and indented (margin-left 30px) so
  process reads separate from the answer; brain comments are brighter.
- **Attachment lightbox** (click/Esc), **turn separators carry the time**
  (new `chat_turn.time` column).
- **Bare URLs render as clickable links** without eating markdown span
  markers (the compounding code-shrink bug on mobile).

## Fixes

- **image.generate mirrors the PNG into the run workspace** and returns
  that path — the canonical artifact in `DATA/images` is outside the
  workspace, so `deliver.files` and the `llm.call` vision re-check were
  refused and a live brain `cp`-ed the file over by hand. The result note
  now says plainly the download is already offered.
- **Dependency CVE fixes:** urllib3 2.8.0 (CVE-2026-97687/8/9), pyjwt
  2.15.0 (CVE-2026-101918); all three lockfiles audit clean.
