# JayNet v1.35.0 — reliable experiment editing

## Bounded editor correction

Harness-experiment Propose and Compose editors now get one corrective retry when
they return malformed JSON or an invalid overlay. The retry includes the invalid
response and exact validation error, so the editor can repair its output instead
of restarting the experiment. A second invalid response aborts; transport
failures are not blindly retried. Token and cost usage accumulates across every
attempt under the same shared cap.

The editor prompt also requires exact names from the current artifact catalog,
preventing an eval case ID from being mistaken for a skill or tool target.

## Learning guide

New sections explain matched Propose–Probe–Compose experiments and scoped
Caveman Compression, including their safety boundaries and the still-unproven
token-savings claim.

## Upgrade

No additional config or schema steps are required after v1.34.0. Restart the
service and check that `/api/health` reports `1.35.0`; this also corrects the
version metadata missed by the v1.34.0 tag.
