# v1.8.5 — shipped prompt: eval-derived directives

2026-09-09 · Prompt-only release, no code changes. The default
`prompts/orchestrator-gate.md` gains the generic, model-agnostic half of
the directives tuned on the live eval loop (setup specifics — GPU layout,
named specialist models, cloud aliases — stay in the local overlay):

- **Answer to the exact spec** (new): re-read output-format rules before
  the final answer — expand abbreviations, all numbers in words, a
  FINAL ANSWER: line is the last text; string manipulation
  (reverse/decode/count) goes through `code.run`, never mental.
- **Deliver the file**: a still-running background process is not a
  deliverable (`job.start` + `job.wait` or synchronous within budget);
  files are created with `fs.write`, never shell heredocs.
- **Prove, don't predict**: when the task ships its own test/checker
  command, run exactly that before claiming done.
- **Batch shell work**: per-turn tool calls are capped — cross-checks go
  in the same call.
- **Don't spin**: an unreachable endpoint gets one alternate transport
  before the task is abandoned.
- Multi-step probability/puzzle problems are never just-replied.
- Authorized security work (pentest/CTF) is routed, never refused.
- The identity line is now model-neutral: "the local orchestrator brain
  on the user's machine".
