Structured preset editor with file pickers and per-flag help, a model files browser with one-click preset drafting, per-binary `--help` viewer, and service restart buttons on the Status page.

- **Structured preset editor** — the raw `.conf` textbox is now a form: one typed field per launch flag (defaults + one-line help), file pickers for model/mmproj/template confined to the models dir. Raw editing stays behind an **advanced** toggle, lossless both ways.
- **Model files browser** — Admin → Presets → *Browse model files…*: collapsible folder tree of the models dir, filtered to `.gguf`/`.jinja` (show-all toggle), ★ marks files a preset references, and *Make preset from selected* drafts a preset for the picked GGUF.
- **Per-binary flag help** — every llama-server binary gets a **help** button (its `--help` output, cached); the `extra args` row links to the same viewer.
- **Service restart** — Admin → Status can restart `litellm-proxy` and the console itself.
- **Fixes** — start-model.sh venv python (CI/minimal distros), mobile menu font, todo-panel collapse, nerd-line shine polish, and the 2026-08-15 audit round (probe key shadowing, `$JAYNET_MODELS` parity, help-cache invalidation, restart logging).

Full details in [CHANGELOG.md](../CHANGELOG.md). Install: see README quick start (`scripts/quickstart.sh` for a throwaway test, `scripts/setup.sh` for a permanent install).
