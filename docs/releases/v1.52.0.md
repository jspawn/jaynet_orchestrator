# JayNet v1.52.0 — durable memory across conversations

This minor release makes explicitly saved preferences available in later chats
and adds an eval that tests that behavior without conversation-history leakage.

## Automatic, scoped recall

- Substantive depth-0 requests search up to three owner-scoped memory entries
  when `tool_selection.recall.auto_memory` is enabled.
- Retrieved evidence remains capped by `max_chars` (1,600 by default). Small
  talk, slash commands and storage requests do not trigger automatic recall.
- RAG remains intent- and collection-gated; this release does not add automatic
  whole-corpus retrieval.
- Disabled tools, parent allowlists and private-recall taint are preserved.

## Explicit capture without duplicate writes

- Requests such as "remember …" or "store …" call `memory.append` once when
  `capture_explicit` is enabled. Entries use `kind: fact`, the `auto-capture`
  tag and `source: explicit-user-request` provenance.
- A system notice tells the model which entry was created and asks it only to
  confirm, not append the same fact again.
- Autonomous extraction of decisions and outcomes is intentionally not enabled.

## Cross-run eval support

`isolate_turns: true` starts every scripted turn with no conversation history
while retaining the same temporary sandbox and memory/RAG/project stores. The
new `evals/memory-cross-run.yaml` case stores a 25 mm Plössl eyepiece preference
in one conversation and requires its retrieval in a fresh one.

## Verification

2,895 tests pass, along with Ruff, mypy, complexity, prompt budgets, generated
docs/rails, dependency audits, ShellCheck and diff hygiene. The new eval has not
yet run against a live brain; run it after deployment to validate model behavior.

## Upgrading from v1.51.2

No dependency or database migration is required:

```bash
git fetch --tags
git checkout v1.52.0
systemctl --user restart jaynet-web
scripts/orch --doctor
```

Then run the `memory-cross-run` eval against the active brain. Automatic memory
recall and explicit capture are enabled in the shipped configuration; set
`tool_selection.recall.auto_memory` or `capture_explicit` to `false` to opt out.
