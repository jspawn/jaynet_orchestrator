# JayNet v1.37.0 — MCP security update

## Security

The optional tools environment now uses `mcp` and `mcp-types` **2.2.0**, fixing
[CVE-2026-59951](https://github.com/advisories?query=CVE-2026-59951).
`requirements-tools.lock` carries the patched pin, while
`requirements-tools.txt` requires `mcp>=2.2.0` for unpinned installations.

LiteLLM's separate environment already uses `mcp==1.30.0`, which is also listed
as patched, so it needs no change.

## Validation

- All three dependency-lock audits report no known vulnerabilities.
- MCP tests pass, and the MCP stdio and streamable-HTTP clients import on
  Python 3.11 and 3.14.

## Upgrade

Refresh the runtime tools environment and restart JayNet:

```bash
uv pip install --python .venv/bin/python -r requirements-tools.lock
```

No LiteLLM environment update, config migration, or browser hard-refresh is
required. `/api/health` should report `1.37.0` after the restart.
