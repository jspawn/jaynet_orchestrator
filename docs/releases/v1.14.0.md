# v1.14.0 — 2026-09-23

A full audit-driven hardening release: the loop becomes a guard pipeline,
non-admin accounts lose their path to a service-user shell, and the eval
harness learns to measure itself. Based on the 2026-09-23 Claude Opus
code audit (`/srv/orch-dev-audits/`), every P1–P4 item except the
deliberately deferred web-layer reshape (#12, opportunistic per the
audit itself).

## Enforcement rails (the bakeoff-lesson batch)

- **Stall hard-stop** (`loop_guard.stall_hard_stop`, default on): after
  the final stall-ladder rung, tool calls close — only
  `specialist.delegate`, `ask.user` or a final answer pass dispatch.
  Refused at call time, never by mutating the tool list (prompt cache
  stays intact); real progress disarms.
- **Repeat-error hard-block** (`loop_guard.hard_block_repeat_errors`,
  default 3): the 4th identical attempt — same tool, args and error — is
  refused without executing. Covers what the duplicate guard misses:
  pre-exec rejections, poll-safe tools, cross-generation repeats.
- **Specialist-authored checks** (`agent.verify_delegate_authored_check`,
  default on): delegations without a project test command must end with a
  strict last-line `CHECK: <cmd>`; the harness runs it through the same
  sandboxed verify runner as auto_verify and hands the brain a
  deterministic `verified: true/false` — no more 4B judging a 27B's diff.
- **fs.read plain text + forgiving fs.edit**: no more JSON-escaped file
  contents (`\n`/`\t` soup); edit matching falls back exact →
  line-number-prefix-stripped → whitespace-normalized → closest-snippet
  error. Trace evidence: 4% of edits failed on a copied `     3\t` prefix.

## The guard pipeline

`AgentRuntime.run` (2,300 lines, complexity ~500) is restructured:
`runtime/run_state.py` holds per-run state; every rail is a registered
guard class in `runtime/turn_guards.py` (pre-turn, post-tool) and
`runtime/final_guards.py` (final-answer). Events, payloads and firing
order unchanged (fake-model suite + AST-identity proof). Every guard
application emits `guard_fired`; **bounce cap**
(`agent.max_bounces_per_answer`, default 3) ends the 8-bounce burn; a
shadowed config key (`agent.stall_check.after` was dead) is fixed. Guard
ablation is now mechanical: benchmark variants accept `guards_off`.

## Security: role-based tool policy

Non-admin accounts no longer reach admin-grade tools
(`security.admin_only_tools`: ops.run, job.*, serve.*, model.use,
git.push, mcp.call, studio.python, schedule.add) — hidden from selection
AND refused at dispatch, including the `/ops.run` slash path.
`auto_confirm` is forced off server-side for non-admin sessions (chat,
goals, voice, schedules); `/goal … | check:` is admin-only. Closes the
audit's P1: any logged-in account could shell out as the service user.

## Eval harness measures itself

- **Provenance columns** on every result row: git_sha, git_dirty,
  prompt_hash, config_hash, specialist_preset, model_files, fallback.
- **Fallback visibility**: the served model is captured per turn
  (`served_model` on `model_turn` events); a specialist→brain LiteLLM
  fallback tags the row `[fallback: requested X served Y]`.
- **Brain-scoped skip-stable**: a brain swap invalidates inherited
  streaks — the first delta under a new brain plays the full library.
- **Uncertainty stats**: `eval-peek.py` prints Wilson 95% intervals;
  `--compare A B` runs McNemar's exact test on paired per-case results.
- **LiteLLM response cache**: local aliases opt out (council votes and
  judge grades carry nonces) — no more replayed answers.

## Typed config + hygiene

pydantic models validate `agent`, `budgets`, `tool_selection`, `eval` at
load: values coerce once in place, unknown keys warn with a did-you-mean
hint, admin saves return warnings (never rejected). New
`runtime/proc.py` replaces ~15 subprocess copies (process-group kill, no
leaked children) and `spawn_background()` tracks fire-and-forget tasks
with shutdown cancellation. CI gains pip-audit (all three lockfiles) and
a mypy baseline gate; ruff gains RUF006+ASYNC; litellm 1.87.0 → 1.102.1
(69 known advisories → 0); devbox tests no longer need podman on the
host. A stable per-chat scratch dir (`<work_root>/.tmp/scratch`)
restores llama.cpp prefix caching across runs — the per-run
`orchrun-<id>` path in the system prompt defeated it.

## Upgrade

Push/pull, then restart. `scripts/setup.sh` rebuilds `litellmenv` from
the refreshed lock (litellm 1.102.1) — watch the first proxy start.
New defaults are on: role policy (check `security.admin_only_tools` if
you run non-admin accounts with elevated needs), stall hard-stop,
repeat hard-block, authored checks, bounce cap. All have config

installs. First eval delta after a brain swap now plays the full
