# v1.20.1 — 2026-10-05

Audit follow-up release. The October audit (claude_audit_05102026)
verified all 14 September findings resolved — tests, lint, types, and
dependency audits all green — and found three new issues, all fixed
here.

## `test.run` / `code.deps` are admin-only (High)

The September role policy closed three doors to a service-user shell
but missed a fourth: `test.run` executes an arbitrary command through
`bash -lc` with the sandbox prefix defaulting to empty, and it was not
on `security.admin_only_tools`. Confirmation is not a cross-account
boundary — the person approving is the person who asked. Both
`test.run` and `code.deps` (installs arbitrary packages, reaches the
network) are now admin-only, enforced at dispatch, slash, and `/goal`.
Refusal tests pin the shipped list and the dispatch path.

## `fs.edit` fails safe (Medium)

The forgiving edit matcher could silently change the wrong thing and
still report `ok`:

- Whitespace normalization collapsed **newlines and indentation**, so
  a match could span differing indentation and splice a statement out
  of its block. The matcher is now line-anchored: leading indentation
  must match exactly, only intra-line space/tab runs collapse.
- Line-prefix stripping also ran on `new_str`, eating legitimate
  content (dict entries like `1: 'one'` lost their keys). `new_str` is
  now de-prefixed only when **every** non-empty line carries the
  prefix shape (a wholesale numbered copy); `old_str` stripping (the
  actual fs.read-copy case) is unchanged.

## Knowledge stores are owner-scoped (Medium)

`memory.*`, `kg.*`, `rag.*`, and pageindex persisted to single stores
with no owner column — on a multi-user box, one account's searches
could return another account's notes, documents, and facts. All four
now filter by `ctx.owner`, with an admin-only, confirmation-gated
`all_owners` escape — the exact pattern the trace tools already used.

One-time migrations stamp existing rows with the first admin's owner
(kg's global unique constraints required a table rebuild with
per-owner composite uniques). pageindex storage moves to
`<data>/pageindex/<owner>`; the legacy root stays the ownerless CLI
store, so pre-scoping indexes remain reachable there — no cross-user
leak, and web accounts simply re-index on demand.

## Low items

Small-brain context/thinking tuning is parked (brain-dependent — the
current cybertiel-35B doesn't need it; revisit when a 4B-class brain
returns). Guard-ablation and the prompt diet were already tracked.

## Upgrade

Push/pull and restart. The store migrations run once on first use;
