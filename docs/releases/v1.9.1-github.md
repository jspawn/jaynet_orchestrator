# JayNet v1.9.1

First public release since v1.4.0 — five weeks of harness work, grouped by
what you get. Full per-version notes live in `docs/releases/`.

## Highlights

**Models are hardware, and the harness drives it**

- Strength routing that actually swaps: tag presets (coding, security, …)
  and `code.delegate` loads the right specialist onto a slot, runs the
  child, and swaps back — the brain returns before the parent's next turn
  (v1.7.2–v1.7.3, v1.9.0).
- Multi-GPU swap planner: `model.use(swap: true)` evicts whatever occupies
  the target port *and* pinned GPUs, waits for port + VRAM release, or
  refuses with a named blocker. Works across cards, with nvidia-smi
  fallback for CUDA boxes.
- Preset editor grew up: standard / all-options / raw views, per-GPU
  checkboxes with live free VRAM.

**One execution verb, enforced routing**

- `code.execute` and `code.run` merged into a single `code.run` with a
  unified result contract (`code.execute` stays as a legacy alias — the
  one breaking change in this span).
- "Route, don't do" is mechanical now: routing nudges, a delegate gate
  that bounces inline edits in strength domains until the first delegate,
  coding-sized delegate budgets, and shell write commands count as coding
  work too.

**The loop watches itself**

- Stall ladder (escalating directives on no-progress turns), wall-clock
  liveness pings, deliverable check + early warning at 75% of the
  iteration budget.
- Procedure library: shape-tagged skills with enforced checklists, plus a
  distillation miner that drafts new procedures from your eval PASS/FAIL
  history (drafts stay hidden until Studio review).

**Eval harness grew teeth**

- Terminal-Bench full mode (deps installed, tests staged, per-case network
  opt-in) — 16 previously unpassable tasks now grade. GAIA benchmark
  added.
- Judge defaults to `local-specialist` — no transcripts leave the box
  unless you choose otherwise; judge calibration harness +
  prompt-injection cases with deterministic canary grading.
- Run delta: skip cases that pass 3× with a 10% random spot-check.
  Results tab, per-case deactivate, multi-select runs.
- Reflect: in-chat corrections become supervised learning proposals.

**Loops, goals, connectors**

- `/loop` command with STATE.md handoff between fresh-context iterations;
  `| check: <cmd>` gives loops and goals a deterministic completion
  signal.
- Guided start (compass button) routes new chats into chat / loop / goal /
  project.
- Connector packages (`.jayconn`): shareable, enable/disable,
  read-only/read-write, SSRF-guarded. New Admin → Connectors tab.

**New senses**

- Vision and STT helper slots: optional `local-vision` (llama-server +
  mmproj) and whisper.cpp slots in the boot posture; mic dictation button
  in the composer; `llm.call` accepts images; `audio.transcribe` tool.
- h5i interactive browser plugin; parallel range downloads in the HF
  puller (2–8× faster).

**Security fixes**

- Brain eviction is internal-only: `include_brain` is gone from the
  `model.use` tool schema — a prompt-injected call can no longer stop the
  run's own model (v1.9.1).
- Connector SSRF guard now resolves DNS and blocks hostnames resolving to
  link-local ranges.

## Upgrade notes

- `code.execute` callers: switch to `code.run` (alias still works, but
  evals and docs assume `code.run`).
- Judge is local by default — if you want the cloud judge back, set it in
  Admin → Eval.
- `models.swap_back: true` is the new default; delegate swaps restore
  evicted models automatically.
