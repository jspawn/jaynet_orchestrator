# v1.14.2 — 2026-09-24

Patch release: route-decision telemetry + audit #23 hardening fixes.

## Routing telemetry

Every depth-0 run now records a `route_decision` trace event:

- `source`: `jev` | `keyword` | `none`
- `tag`, `confidence`, `latency_ms`
- `keyword_tags`: the keyword baseline, always computed even when a hook
  answers — jev-vs-keyword agreement is now queryable from trace.db
  without re-running anything.

The routing hook contract extends to `{tag, confidence, source}` dicts;
plain strings still accepted (backwards compatible with existing
plugins).

## Audit #23 fixes

- **B1 — ablation pin.** The final-turn tool registry is always built
  complete; `guards_off` skips only the guard *checks*, so the
  deliverable pin survives guard ablation instead of vanishing with
  them.
- **C1 — keyed scratch.** `run(scratch_key=…)` is explicit: web chat
  and voice key by conversation_id, child runs auto-key by run_id. The
  cross-run scratch-bleed class is closed.
- **D1-D4 — drift.** Static asset cache-bust (?v=44), catalog regen,
  changelog sentence, admin.md archived-flag docs, version cites in
  api.md / LEARNING_GUIDE.

## Upgrade

Pull, restart services. No config or DB changes required (trace.db
gains the new event kind automatically). Live `presets.db` migrates the
`archived` column from 1.14.1 on first boot if not already applied.
