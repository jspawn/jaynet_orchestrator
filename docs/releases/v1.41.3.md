# JayNet v1.41.3 — LiteLLM auth error handling

This patch adds Prisma to the otherwise stateless LiteLLM proxy environment.
LiteLLM 1.102.2 imports it from the authentication error handler even without a
configured database; without the package, a missing API key caused an HTTP 500
instead of the intended HTTP 401.

Only `prisma` and its `nodeenv` dependency were added, not the database extra.

## Upgrading

Pull, sync the proxy environment and restart LiteLLM:

```bash
uv pip install --python litellmenv/bin/python -r requirements-litellm.lock
systemctl --user restart litellm-proxy.service
```
