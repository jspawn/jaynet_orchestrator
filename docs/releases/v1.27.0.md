# JayNet v1.27.0 — measurable tools, measurable strengths

The eval side of the admin grows teeth: per-tool telemetry as a button,
a transposed strength matrix with podium shading, registry-driven case
mapping — and the playbook now argues from those numbers. 2,363 tests
green; all gates clean.

## Tool telemetry, standing

`scripts/tool_value.py` reads the live trace DB (read-only) and prints
per-tool calls, error rates, run share and ok-rate contrast — also as the
**Tool telemetry** card in Studio & Eval → Eval. This turns "which tools
earn their keep / what do we trim or develop" from a prose debate into a
query. First readings: `architect` called once in 3.9k runs, the
`research.*` state spine nearly untouched, `note.set` 26× `memory.append`
(the confusion the memory-vs-note eval guards), `web.fetch`'s 33% error
rate is the escalation ladder working as designed.

## Strength matrix: transposed, shaded, registry-driven

Brains run downwards, strengths across (the brain list outgrew the
columns); the top-3 cells per strength get decreasing green shades. And
case→strength mapping now matches case tags against the admin-editable
`models.strengths` registry directly: tag a case `bugtrace` and it
measures under `bugtrace` with no code change. The alias table
(`tb` → coding, …) and `strength:<tag>` pins are unchanged.

## Playbook refresh

Tool families, harmonies, competition notes and verdict are current
again — new media/senses family, pageindex as a fifth knowledge surface,
the h5i lane, decision classifiers, measured scheduling; solved verdict
items removed; §6 cites the telemetry.

## Preset editor: themed multiselects

Device and strengths are dropdowns now (button + checkbox popover in the
admin theme) instead of inline checkbox rows that wrapped badly. CPU
stays exclusive with GPU picks; tag meanings ride the option tooltips;
unregistered tags a preset carries stay listed.

## Upgrade notes

Pull, restart, done — no config or dependency changes. New tag → new
measurement: add a case tagged with your custom strength and watch the
matrix fill in.
