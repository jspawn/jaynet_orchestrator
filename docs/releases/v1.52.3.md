# JayNet v1.52.3 — runtime, process, and web hardening

This patch rolls up the verified audit findings after v1.52.2: correctness,
privacy, lifecycle, and performance fixes across the agent loop, model launchers,
subcalls, Studio, and web stores.

## Agent loop and process lifecycle

- Auto-delegate notes follow tool results, parallel child cancellation
  propagates, and dynamic private flags survive execution.
- Child budgets cannot turn zero-valued caps into unlimited spend; spawn vision
  and cloud gates use run-local config and privacy permissions only narrow.
- Managed processes use shell-free argv and `start_new_session`, drain arbitrary
  log lines, reap before restart, and kill the whole process group on timeout.
- Background shutdown uses `asyncio.wait`, so cancellation-resistant tasks
  cannot stall teardown. Log tails and reaping are bounded.
- Model HTTP calls use a 10-second connect timeout, served-model matching is
  separator-safe, and shared clients close during app shutdown.

## Launchers and mediated subcalls

- vLLM accepts local model directories; GPU lists are normalized before device
  environment rendering.
- Subcalls validate model and token arguments, use mode-0600 UNIX sockets,
  await writer closure, revoke each execution grant in `code.run`'s `finally`
  path, and accumulate response chunks efficiently.

## Studio and web

- Studio skill edits refresh the live system-prompt catalog immediately;
  nested custom tools are edited at their existing path instead of duplicated.
- Voice runs use per-user budget governance and fail dynamic confirmations
  immediately rather than waiting for a nonexistent approval UI.
- The scheduler loop is tracked by shutdown. `/admin/` requires admin access.
- Project output promotion skips direct and nested symlinks instead of copying
  their targets into the workspace.

## Persistence and performance

- Tool override saves use unique atomic temp files and ignore null descriptions.
- SQLite reads use safe URI paths and guaranteed close; store WAL/permission
  setup runs once per instance, and user lookups include `session_epoch`.
- Environment scrubbing is case-insensitive, directory suggestions are capped,
  telemetry avoids repeated run-map scans, and upload writes leave the event loop.

## Verification

2,954 tests pass, including real long-line process output, cancellation-resistant
shutdown, concurrent override saves, subcall socket/grant lifecycle, Studio hot
reload, voice governance, and symlink-escape regressions. All release gates pass.

## Upgrading from v1.52.2

No dependency or database migration is required:

```bash
git fetch --tags
git checkout v1.52.3
systemctl --user restart jaynet-web
scripts/orch --doctor
```

Managed-process commands are shell-free argv. If you added custom entries with
shell assignments, move those values into `processes.*.env` before restarting.
