# JayNet v1.29.0 — themed checkboxes, AI-assisted setup

A small polish-and-onboarding release on top of the v1.28.0 rollup.
2,365+ tests green; all gates clean.

## Themed checkboxes

Native checkboxes now render in the house style — panel-colored box,
accent fill with checkmark when checked, dimmed when disabled — in both
the chat UI (file manager, flag modal, todo lists) and the admin console
(brows, tables, the strengths/device multiselect popovers, the "show
archived" toggles). The toggle switches keep their own look. With this,
the one-control-language arc that started in 1.27 is complete.

## AI-assisted setup

New [docs/ai_assisted_setup.md](docs/ai_assisted_setup.md): a paste-ready
playbook you hand to an AI coding assistant (Kimi Code, Claude Code, …)
on the target machine. It walks the install in phases — distro packages,
quickstart vs permanent install, llama.cpp builds per GPU backend,
hardware-tiered HuggingFace model suggestions, first config, and a
per-plugin opt-in menu with one-line pitch and cost each — asking before
anything that costs disk, money or sudo. Ends with `orch --doctor`
validation and the first-steps checklist. The quickstart, guided and
manual install paths are unchanged.

Alongside, an install-path audit verified `setup.sh` and
`manual_installation.md` against the current tree; two staleness fixes
shipped (the `--with-tools` help now names the pinned lock; the manual
no longer claims the shipped prompt names the author's models).

## README front

The hero shot is paired with the presets page — *model swapping in
action* meets *the swapper's cockpit* — and the docs screenshots are
current again.
