# v1.18.6 — 2026-10-05

Feature release: imagegen can free the whole machine for a big
generation, and the h5i plugin exposes the full red-team verb surface.

## imagegen: hibernate several slots — brain included

`swap_slot` was a single slot: a big image could free the specialist's
VRAM but never the brain's — a problem when the specialist spans both
cards and the brain holds the rest. The new `swap_slots` config
(`[specialist, brain]`, merged with `swap_slot`, back-compatible) stops
every listed slot before a generation and restores them cancel-safe in
reverse order. A hibernated brain is restored **immediately** after the
generation — not after keep-warm idle — with a readiness wait
(`restore_ready_timeout_s`, default 300; port discovered via the preset
store, falling back to the launch command), so the parent run's next
turn never hits a dead model. The tool result names what was hibernated
and any slot that missed its readiness window. The no-in-flight-lock
trade (another run mid-turn on the brain while it's hibernated breaks
that run) is documented in the README — same trade as the specialist
delegation's brain eviction.

## h5i: the full red-team verb surface

- `browser.recon` gains `paths` — wordlist probing, request-bounded
  (`--max-requests`/`--rate`, same defaults as crawl).
- `browser.websec` gains seven actions: `experiment` (one request many
  ways, clustered), `matrix` (one request under several identities —
  authz/IDOR testing), `sequence` (multi-step flows with bindings),
  `socket` (WebSocket frames), `dom` (prototype-pollution and DOM-XSS
  source→sink probes), `grpc` (describe a service / call a method) and
  `import-nuclei` (convert a Nuclei template into an h5i-test file).
- New tool `browser.test` wraps h5i-test: replay portable attack flows
  and check them with repository-owned oracles (optional OpenAPI
  coverage denominator). It ACTIVELY attacks the target —
  `requires_confirmation`, description leads with AUTHORIZED TARGETS
  ONLY.

Plans and wordlists are accepted inline (written to a scratch file) or
as workspace files. The abstract-base "empty name" catalog warning is
gone; the plugin is now 22 tools.

## Upgrade

Pull, restart `jaynet-web`. Optional config: `plugins.imagegen.swap_slots`
and `restore_ready_timeout_s` (both commented in the shipped
`config/runtime.yaml`). For the both-GPUs posture on a two-tenant box:
`swap_slots: [specialist, brain]`. The new h5i verbs need the h5i
recon/websec/test plugin binaries installed (`h5i plugin install …`).
