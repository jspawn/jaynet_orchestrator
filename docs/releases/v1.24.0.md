# v1.24.0 — prompt diet + audit ledger cleared

Minor release on 1.23.1. Closes every remaining actionable item from the
2026-10-11 audit ledger (and the carried-over Tier-2/3 lists): the
dispatch-mode prompt variant, guard telemetry, the test.run sandbox
default, the ORCH_→JAYNET_ env migration with a drop date, the ruff
hygiene baseline, and the glossary marking. 2,346 tests green; all gates
clean, including the new ruff-hygiene baseline (101 grandfathered).

## Dispatch mode gets its own prompt

`brain_mode: dispatch` now runs `prompts/orchestrator-dispatch.md` — 505
words against the gate prompt's 1,855. A dispatcher plans, routes,
verifies and answers; the harness rejects its inline code authoring, so
the 1,300 words of authoring doctrine were pure cost. The variant keeps
the routing mechanics, verify-by-running, requirements extraction, answer
exactness and conflict surfacing, and drops what the dispatch brain can't
act on. Configured via `orchestrator.dispatch_prompt`, with the same
shipped/overlay layering as the gate prompt (live edits in
`$JAYNET_DATA/custom/` win, stale overlays warn). The prompt joins the
word-budget CI gate (cap 550).

The second half of the audit's prompt-diet item — trimming the
always-loaded core toolset — is deferred by design: trace.db call counts
say `context.pin`/`memory.get`/`gpu.status` are rare at depth 0, but
dropping them costs a `tools.load` round-trip when they're needed. That
trade gets its own A/B before it ships.

## Guard telemetry: eval-peek reads guard_fired

`scripts/eval-peek.py` now shows per-case guard fires and a per-guard
aggregate — fires, cases involved, pass-rate-when-fired vs
pass-rate-when-quiet. First live reading: `requirements` and `procedure`
are pure rescuers (100% pass-after-fire), `verify_arm` nets +8 points,
while `cap`, `wrap_up` and `trunc` only ever see doomed runs — the next
guards_off ablation reads its candidates straight off this table.

## Smaller items

- **`test.run` sandboxes by default** — firejail prefix, network kept ON
  (suites may need it), graceful degrade to a bare run with a warning when
  firejail is missing, `[]` opts out. Defence in depth on an already
  admin-only tool.
- **ORCH_* → JAYNET_* finished** — every env read goes through
  `runtime/env.py`: the new name wins, the old name falls back with a
  one-line deprecation warning (once per process per name). **The ORCH_*
  fallback is slated for removal with v1.25.0** — `docs/upgrading.md` has
  the one-line `sed` migration for the env file.
- **Ruff hygiene baseline** — B904 (raise without `from`) and S110
  (try/except/pass) now gate CI via `scripts/check_ruff_hygiene.sh` with
  a committed 101-site baseline; new violations fail, the baseline only
  shrinks.
- **Glossary** marks plugin-backed terms; playbook/architecture link
  house terms on first use.

## Deliberately deferred

h5i network isolation (plugin off by default; the fix is a network
namespace, not code), the web-layer route/JS bulk (L-sized, do it when
touching those modules anyway), and the always-loaded toolset trim
(needs its A/B).
