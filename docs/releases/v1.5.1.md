# v1.5.1 — loops, checks, and connectors

2026-08-28 · Feature release. Three additions that share a theme: the
right tool for the job should be easy to pick, and finishing a job should
be provable. No breaking changes.

## Highlights

- **`/loop` — the fresh-context objective loop** (the "Ralph" pattern).
  Same grammar and supervision as `/goal` (`| done when:`, pause/resume/
  stop, ceilings, completion judge), but every iteration launches with an
  EMPTY context window: no accumulated history to degrade, no compaction
  drift. The workspace files are the loop's only memory — the harness
  captures STATE.md between iterations and injects it into the next
  continuation, so even small models can't lose the plot. Turns publish as
  🔄. Use `/loop` for long marathons on smaller models, `/goal` when
  conversation context matters.
- **Deterministic completion: `| check: <cmd>`.** Optional on `/loop` and
  `/goal` (any order in the grammar): on every completion declaration the
  command runs in the goal's workspace — exit 0 finishes, anything else
  logs the output and feeds it into the next iteration. A check replaces
  the judge (deterministic outranks model opinion);
  `goal.check_timeout_s` (default 120) bounds it.
- **Guided start.** The compass button next to *new chat* asks "what would
  you like to achieve?" plus two short questions and routes to plain chat,
  `/loop`, `/goal`, or a new project — prefilling the composer, never
  auto-sending. Choosing the right tool is no longer the hard part.
- **Connector packages.** Connectors grow from single declarative HTTP
  tools into shareable SYSTEM packages — one connector = one external
  system (Gmail, the LAN mail server, an ERP) exposing a tool namespace.
  Data, not code (the deliberate line to plugins): a pack is interpreted
  YAML, secrets are env-var names, box state lives per-installation — a
  `.jayconn` is safe to share by construction. Enable/disable and
  read-only/read-write per connector, hot (RO drops write tools entirely;
  new packages with writes start read-only). New Admin → Connectors tab
  with settings forms, a test probe, export/delete, and an SSRF guard
  (link-local/metadata base_urls rejected; homelab ranges stay allowed).
  Legacy single-tool connectors keep working unchanged. Authoring guide:
  `handoffs/connectors.md`.

## Upgrade notes

Pull, restart both services. Existing connectors appear in the new tab
untouched. `/loop` needs nothing configured — try it on a small task with
a `| check:` you can verify by hand first.
