# JayNet v1.26.0 — strengths admin UI, measured VRAM everywhere

Models-tab ergonomics release: the strength-tag registry no longer needs
a YAML edit, the presets table shows real measured footprints, measuring
is a per-row button, and the docs screenshots are current. 2,358 tests
green; all CI gates clean.

## Admin → Models → Strengths card

Manage the tag registry (`models.strengths` name→meaning +
`agent.role_temperature` child temperature) without touching YAML: list
(with carrier presets), add, inline edit, reset-to-shipped. Entries
persist as admin config overrides and apply on the next run — the brain's
strength directory renders per run, so a new tag is routable immediately
(`specialist.delegate strength="…"`). Shipped defaults can be edited and
reverted; custom tags disappear on reset.

## Presets table

- **VRAM shows the measured footprint** (`model.measure`) instead of only
  the hand estimate: `✓` current measurement (tooltip: date, per-GPU
  split, RAM), `~` stale (ctx/GPU edited since — the loader ignores it,
  re-measure), `?` estimate, `—` unknown. The staleness verdict is the
  planner's own rule, exposed as `measured_stale` in the payload.
- **Measure button per row** (local, aliased, non-archived presets):
  runs `model.measure` as a background job — one at a time, the click
  standing in for the confirmation. The VRAM cell refreshes on done.
- **Strengths are a registry multiselect** in the preset editor —
  checkboxes with the tag meanings as tooltips; an unregistered tag a
  preset already carries stays checked and marked.
