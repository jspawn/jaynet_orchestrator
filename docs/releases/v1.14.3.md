# v1.14.3 — 2026-09-29

Patch release: imagegen goes live, audit #24 hardening fixes (two
correctness/privacy criticals), delegate iteration cap, brain bakeoff
columns Bonsai-27B + qwen35-9B.

## imagegen — local text-to-image, live

`image.generate` (plugin `imagegen`, Qwen-Image-2.1 GGUF via
stable-diffusion.cpp) proved end-to-end on the live box: the tool
hibernates the specialist slot, serves sd-server on loopback,
generates, and the keep-warm reaper restores the slot after an idle
window — the full swap lifecycle verified with a real 1024×1024
render.

- The PNG is staged as a **user download by the tool itself** — the
  artifact lives in `DATA/images`, outside the run workspace, so a
  brain-side `deliver.files` on it was refused (found by the first
  live smoke generation).
- sd-server is registered on the shutdown path: a JayNet stop during
  a keep-warm window no longer orphans a GPU-resident process.
- The keep-warm reaper runs as a tracked background task
  (`runtime.proc.spawn_background`) instead of a bare `create_task`.

## Audit #24 fixes

- **C1 — scheduled runs key their scratch.** The unattended launcher
  was the last `runtime.run` caller without `scratch_key`; the
  start-of-run wipe cleaned the shared `.tmp/scratch` and deleted the
  keyed scratch dirs of runs in flight (a nightly run starting
  mid-chat wiped the chat's temp files). Fixed with
  `scratch_key=run_id` + regression test.
- **C2 — delegation review respects the cloud/taint gate.** The
  fresh-context review ships task + specialist report + evidence to
  its alias chain — and a cloud-pinned `tools.code.delegate.model`
  sent that off-box with no gate, while the child run's own turns
  were gated. A privacy-tainted run now restricts the chain to local
  aliases (fail-safe, same posture as `cloud_gate.privacy_refusal`);
  untainted runs are unchanged. Advisory design (skip = non-fatal)
  preserved.
- **D1-D6:** api.md version cite, catalog regen plus a **CI
  freshness check** that fails on gen_catalog drift (third audit
  cycle with the same miss — class closed), re-shot presets/plugins
  screenshots (duplicate button, greyed disabled cloud rows, six
  plugins), brain-bakeoff totals row filled for six played columns,
  sd-server lifecycle registration, the mypy gate fails closed when
  the binary is missing.
- Carry-over docs closed: development.md CI pythons (3.11+3.14),
  configuration.md stall keys (`agent.stall_check.*`), playbook.md
  procedure shape list, `tests.`-prefixed imports in three test
  files. #23 C2 (bounce cap accepts flagged answer) stays open by
  design pending eval coverage.
