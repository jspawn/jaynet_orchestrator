# v1.18.4 — 2026-10-05

Patch release: the inline media players render dark in dark mode.

## `color-scheme: dark`

The dark theme never declared a `color-scheme`, so the browser fell back
to light chrome for native controls — the new `<audio>`/`<video>` players
rendered white against the dark chat. `:root` now declares
`color-scheme: dark` (`body.light` keeps its `light` override, so light
mode is unchanged). Other native controls — scrollbars, form inputs —
follow the dark palette too. The css cache-buster is bumped (`?v=48`),
so clients pick it up without a hard refresh.

## Cache-buster test fix

Bumping that buster exposed a latent bug in the v1.18.3 buster gate:
`_worktree_diff` joined two empty `git diff` outputs to a truthy `"\n"`,
reading any *clean* asset as an uncommitted edit — the app.js case went
red the moment the tree was clean after the release commit. Clean files
now compare against committed history as intended; the dirty-asset and
uncommitted-bump directions are unchanged.

Pull, restart `jaynet-web`. No config change.
