# JayNet v1.28.0 — the October arc: measured models, enforced discipline, one console

Rollup of v1.16.0 through v1.28.0 (the individual releases were folded
into this one). Fourteen tags of work since v1.15.1: the brain is now
occamy 1.0, the loader schedules by measured VRAM, the loop guards its
own discipline with telemetry to prove it, tools and strengths are
measurable from the live trace DB, JayNet speaks (TTS) and reads long
PDFs, and the admin console went from 16 flat tabs to one control
language. 2,365 tests green; all CI gates clean.

## Brain & models

- **occamy 1.0 is the reference brain** — 20/30 on the flip-set, 74/93
  on the full delta; `brain-occamy-1-0.conf` ships as reference, with
  `MTP_MODEL` support for separate draft files.
- **Measured memory scheduling**: `model.measure` hibernates the box,
  loads a preset alone and writes real per-GPU VRAM + RAM into the
  catalog. The loader packs by measured fit — a second model loads
  alongside a half-full GPU tenant instead of evicting it.
- **Strengths are admin-managed**: Admin → Models → Strengths edits the
  tag registry (name→meaning + child temperature) without YAML; a new
  tag is routable on the next run. Preset editor uses themed
  multiselects for device + strengths; presets table shows measured
  footprints (`✓` current / `~` stale / `?` estimate) with a per-row
  **measure** button.
- **Benchmark views focus on what you have**: strength matrix
  transposed (brains down, strengths across) with top-3 podium shading,
  registry-driven case mapping (tag a case `bugtrace`, it measures
  under `bugtrace`), and both benchmark views default to current
  presets with retired labels behind a "show archived" toggle.
- New strength tags and specialists along the way: `bugtrace`, OSINT
  (redcell 26B — the "malformed GGUF" verdict was the mmap path,
  `MMAP=off` fixes it), a gemma-4-31B vision specialist.

## Harness discipline

- **The brain sees its budget**: per-turn `budget: iteration 3/8`
  readout; the motivating flake class went 5/5.
- **j-space protocol enforced**: writes and delegation are rejected
  until `run.badge` + a todos plan exist; the salvage lane and shell
  heredoc bypasses were closed as found.
- **Stall ladder calibrated by ablation**: fresh research turns are
  ladder-neutral, delegated-and-verified runs never hard-stop, an armed
  hard stop is disarmed by real edits.
- **Prompt diet**: dispatch mode gets its own 505-word prompt (the gate
  prompt is 1,855), picked per run, with a CI word budget. Overlay
  drift is detected and flagged in Admin → Harness → Prompts.
- **run() refactor complete**: 2,594 → 767 lines; the 16 inline
  pre-exec checks are now an ordered, telemetry-visible gate pipeline
  in `runtime/dispatch_guards.py` (security gates non-ablatable).
- **Guard telemetry**: eval reports end with per-guard fire/pass rates
  — `requirements`/`procedure` are pure rescuers, `cap`/`wrap_up` only
  see doomed runs.
- **Verification got teeth**: authored checks must go red→green against
  a spawn-time tree snapshot; vacuous checks (`assert … or True`) fail
  deterministically; undeclared test edits name the protected files and
  the `allow_test_edits` remedy; eval `max_iterations` is now a real
  budget.

## Tools & procedures

- **`procedure.save/run/list`** — the reasonlet/metacache pattern: the
  model writes deterministic logic once as an inspectable script; later
  runs re-execute it with zero model tokens (sandboxed, network off,
  120s cap). Gated like any write; slugs validated.
- **Tool telemetry**: `scripts/tool_value.py` and the Studio & Eval →
  Eval card print per-tool calls, error rates and ok-rate contrast from
  the live trace DB — "which tools earn their keep" is now a query, not
  a debate.
- Tools declare `admin_only` on the class, enforced at selection,
  dispatch and slash; `test.run` runs firejail-sandboxed by default.

## Media & plugins

- **omnivoice**: local TTS (`audio.speak`, 600+ languages, voice
  design, fixed vocabulary of style tags) and `audio.clone`; generated
  audio/video plays **inline in chat** (dark-mode aware, download chip
  kept). The **read-aloud** chain is the first model-switching chain:
  creative preset → mood-tagged chunks → TTS stitching.
- **pageindex**: vectorless tree index over long PDFs
  (`doc.index`/`doc.tree`/`doc.pages`), cloud-gated, owner-scoped.
- **imagegen**: server-side artifacts land in the run workspace;
  `swap_slots` hibernates brain/specialist slots during generation and
  restores them cancel-safe.
- **h5i is a full red-team browser**: browse/submit/scroll/screenshot/
  audit, `browser.recon`, `browser.websec` (private), `browser.test`
  (confirmation-gated — it actively attacks). SSRF-guarded, loopback
  refused, per-call `allow` can only narrow.

## Security & privacy

- Knowledge stores (memory, kg, rag, pageindex) are **owner-scoped**
  with automatic first-boot migration; `all_owners` is admin-only —
  for real now, not confirmation theater.
- Role policy fails closed: non-admins lose local `/imp` swaps,
  `test.run`, `code.deps`, `model.measure`.
- Auth hardening: login throttle keyed on username+IP, single-use TOTP,
  random `session_epoch` for new accounts; deleting a user deletes
  their schedules, knowledge and traces.
- `fs.edit` fails safe against line-number-paste artifacts; harness git
  calls run hooks-free; j-space gate bypasses closed as found.

## Console & docs

- Admin went from 16 flat tabs to 6 top-level tabs with subtabs and
  hash redirects; **one control language** — selects, buttons and
  multiselects share the themed styling everywhere.
- Overview card auto-probes sidecars (searXNG, jev) and an
  update-check card reports h5i/jevify/llama.cpp/litellmenv drift.
- Chat: attachments persist in turns, same-tool rows group, lightbox,
  clickable bare URLs; nerd-theme prompt shine starts at the `❯`.
- Docs refresh across the arc: `docs/turn.md` (life of a turn),
  `docs/rails.md` (generated guard registry), decision log D001–D030,
  playbook rewrite arguing from telemetry, five new LEARNING_GUIDE
  lessons, 28 screenshots regenerated.

## Upgrade notes (from v1.15.1)

1. Pull, restart — migrations (presets.db measured column, knowledge
   owner-stamping) run automatically on first boot.
2. **ORCH_\* → JAYNET_\*** env rename: dual-read with a deprecation
   warning; the fallback goes away with the first release on/after
   2026-12-01. One sed line in docs/upgrading.md.
3. **Re-run `model.measure`** for your active local presets (Admin →
   Models → Presets, per-row button) — pre-1.23 RAM numbers
   undercounted mmap'd weights.
4. Optional: `pip install pageindex`; omnivoice needs the tts-server
   build + ~1 GB GGUFs; `test.run` sandboxing wants firejail. All three
   degrade gracefully when absent.
5. If you carry a local `runtime.yaml`, merge the additive keys
   (`agent.verify.unprotect`, `call_timeout_overrides`,
   `plugins.imagegen.swap_slots`, `models.min_free_ram_gib`) — the
   typed config schema will warn you about unknown keys either way.
6. Behavior tightenings to expect: non-admin accounts lose
   `all_owners` reads, local `/imp` and `model.measure`; h5i refuses
   loopback targets; eval `max_iterations` caps are real now.
