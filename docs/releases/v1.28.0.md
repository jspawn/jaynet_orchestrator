# JayNet v1.28.0 — consistent controls, focused benchmark views

A UI polish release on top of v1.27.0: one control language across the
admin console, and benchmark views that default to the models you
actually have. 2,365 tests green; all gates clean.

## One control language

`select` and `button` now share the input styling — same font, size,
panel background and border — so boot model slots, benchmark dropdowns
and every other native select in admin stop rendering in the OS-native
look. Together with 1.27.0's themed multiselects (device picker,
strengths), the console speaks one control language throughout.

## Benchmark: current presets by default, archived behind a toggle

The **Compare** picker and the **strength matrix** defaulted to every
brain label ever recorded — retired brains, harness variants like
`guards_off`, typo'd labels. Now both default to labels that map to a
current catalog preset (name, alias or served_id, dash/underscore
insensitive — results record served_ids); everything else sits behind a
synced **show archived** toggle on either card, with a "(N archived
hidden)" hint. Podium shading ranks visible cells only.

## Screenshots current

The docs screenshots were regenerated against the post-1.27 live UI —
themed controls, the chat hero's ❯ prompt shine, the strengths card and
measured VRAM column on the presets page.

## Upgrade notes

Pull, restart, done — no config or dependency changes.
