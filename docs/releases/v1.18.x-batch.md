# JayNet v1.18.x — release note (v1.18.0 → v1.18.4, 2026-10-03 → 2026-10-05)

Five tags in one window: two behaviour features that shipped **on**,
one experiment that shipped **off** with its numbers written down, and
two audit-driven hardening passes that closed the full #27/#28 ledger.

## Highlights

- **The j-space protocol is now enforced, not just advised.** Live evals
  showed the brain skipping the j-space badge 3/3, then dodging the plan
  step via file-based ledgers and unplanned delegation. The
  `loop_guard.jspace_badge_gate` (default on) rejects file writes and
  delegation until `run.badge` AND a todos plan exist — and after audit
  #28 it covers the bypasses too: `code.run` heredocs, `sed -i`,
  `code.patch` and `agent.fanout` all walk into the same gate via the
  repo's `_gate_write_like` predicate. Gate state lives in the loop, not
  in a removable nudge guard, and the gate is ablatable by name for
  benchmark studies. Validated 3/3 live.
- **Budget visibility that measurably works.** A one-line per-turn
  readout (`budget: iteration 3/8`) sits at the prompt tail, and evals
  enforce their declared `expect.max_iterations` as a real budget — the
  over-verification flake class that motivated it went 5/5 on the first
  post-fix delta.
- **Inline audio/video in chat.** Generated media (omnivoice WAVs, mp3,
  flac, mp4, webm, …) renders as inline `<audio>`/`<video>` players
  where the deliver happened — `preload="none"`, download chip kept, and
  since v1.18.4 they render dark in dark mode.
- **omnivoice speaks its server's real language.** The TTS
  `instructions` field is a fixed vocabulary (male|female, age band,
  pitch, whisper, accents), not free prose — every teaching copy (tool
  description, skill, chain, plugin.yaml, playbook, docs) said otherwise
  and every "dark voice" request failed. All copies now teach the
  vocabulary, and full server error bodies reach the model for a
  one-shot retry.

## Verification & trust

- **Caller-declared tamper exceptions.** `specialist.delegate
  allow_test_edits` lets the brain declare test paths a task legitimately
  modifies — fixing the recurring "verifier stuck" deaths when a task
  *requires* a test edit — without weakening the guard every undeclared
  case depends on. Declarations are normalized (`./x.py` ≡ `x.py`),
  diagnosed when they match nothing, and every applied waiver leaves a
  `[tamper waiver active]` record in trace.db. `agent.verify.unprotect`
  is a real config key now.
- **Timeout wrapper fits the tools.** `llm.call` was killed 17× and
  `agent.fanout` 12× at exactly 180 s (vision/OCR calls, fan-out runs).
  Overrides added (`llm.call: 660`, `lint.run: 360`,
  `image.generate: 1260`, `agent.fanout`/`chain.run: 0`) plus a
  completeness test so the table can't silently drift again.
- **pageindex is cloud-gated.** Building an index sent document text to
  any configured alias while docs claimed "nothing leaves the box" — the
  build path now runs the core cloud-gate machinery (local alias fine,
  cloud + private taint refused, cloud builds ask first).
- **Media plugins survive cancellation.** A `CancelledError`
  mid-generation skipped slot restore and disarmed the keep-warm reaper;
  both plugins clean up on `BaseException`. Artifact names can't
  collide, mirrors re-copy stale files, returned paths always exist, and
  `audio.clone` bounds reference WAVs at 25 MB.

## Measured and rejected

- **`agent.state_file` (CLM-style self-managed `state.md`)** was built,
  A/B'd live across 24 suites with a purpose-built two-arm driver
  (`scripts/eval-ab.sh`), and measured: no pass-rate benefit, +30%
  tokens, ~2× wall time. Shipped **off**, code kept behind the flag,
  numbers in `docs/clm-bakeoff.md`. The A/B driver itself got hardened
  (trap, honest restore, loud failures) in the same window.

## Hygiene

- Cache-busters bumped for every static change, with a git-history test
  that fails when `app.js`/`app.css` move without the buster line —
  closing a 4×-recurring lapse class.
- 25 retired admin-tab references swept across 20 files; doubled
  breadcrumbs fixed; `default_sub_iterations` comment matches the real
  default (16); `docs/configuration.md` + glossary cover the new gate
  and `state_file`.
- Release hygiene: every commit in the window self-consistent
  (version ↔ changelog ↔ release file ↔ README), five clean tags.

## Upgrade

Pull, restart `jaynet-web`. If you carry a local `config/runtime.yaml`,
merge the additive new keys: `agent.verify.unprotect: []`, five
`call_timeout_overrides` entries, `agent.anchor.budget`,
`agent.state_file.*`, `loop_guard.jspace_badge_gate` (all have safe
shipped defaults). Note for j-space runs: the gate now also rejects
shell writes pre-badge — one instructive rejection ("badge first, then
re-issue") instead of a silent bypass.
