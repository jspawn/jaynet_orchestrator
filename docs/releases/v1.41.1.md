# JayNet v1.41.1 — live self-test fixes

Patch release driven by a full live tool/skill self-test. The complete report,
including reproductions and coverage limits, is in
`docs/selftest-2026-10-29.md`.

## Fixes

- **Direct specialist delegation:** `slash_spawn` accepts and forwards
  `sampling`, so `specialist.delegate` no longer fails when role sampling is
  configured.
- **uv-created Python environments:** `code.deps list` uses `uv pip list`
  instead of requiring pip inside the venv.
- **Linter selection:** automatic `lint.run` checks are file-type aware.
  Python files no longer fail merely because shellcheck is installed;
  explicit `linters=` and custom registry entries retain override behavior.
- **h5i 0.5 compatibility:** one-shot `browser.browse read` now uses snapshot
  plus close, and `open` relies on h5i's default capture instead of the removed
  `--capture` flag. recon/websec/test also find h5i in `~/.local/bin` when the
  service PATH omits it. h5i docs now cover the `agent-browser` dependency.

Each fix has regression coverage and its own commit.

## Verification

All 39 discovered skills loaded successfully. The self-test verified 117 tools
before these fixes and identified four actionable defects plus the h5i PATH
fallback issue. After the fixes, **2,685 tests pass** and all CI gates and
dependency audits are clean.

## Upgrading

Pull and restart. No migrations or config changes are required. For h5i 0.5
browsing, install the `agent-browser` CLI and its Chrome runtime, for example:

```bash
agent-browser install
```

The binary is available through npm, Cargo, Homebrew, or pinned GitHub release
assets; see the h5i plugin README for details.
