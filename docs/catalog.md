# Catalogue — tools, skills, chains, slash commands

> Generated by `scripts/gen_catalog.py` — re-run it after adding or
> editing tools, skills or chains. Descriptions show the first line;
> the model sees the full text, and Admin → Tools toggles what is offered.

## Slash commands

Type `/` in the composer to pop the filtered list; `<namespace>.` drills
into that namespace's tools, Tab completes.

| Command | What it does |
|---|---|
| `/help` | command overview — /help tools, /help <tool> |
| `/compact` | summarize older history into a continuity brief |
| `/imp` | impersonate another model as brain — /imp list; ends with /impstop |
| `/impstop` | stop impersonating; back to the default brain |
| `/wgs` | skill-authoring session (writing-great-skills playbook) |
| `/llmwiki` | view/grow/prune your LLM-maintained wiki (project or global) |
| `/goal` | pursue an objective across runs — /goal <objective> [| done when: …] |
